# 兵種別の近接戦闘

作成日時: 2026-09-06 09:40
更新日時: 2026-09-06 12:09

## 起動と操作

素材確認・隊列確認・戦闘試作でF7を押すと、刀武士同士の戦闘を初期化する。Spaceで進軍・一時停止、Homeで同じ兵種の戦闘を初期化する。関ヶ原画面からは「兵種を見る」を経由する。

```powershell
$appPath = '.\build\Release\sengoku_rts.exe'
& $appPath --sword-battle
```

`--battle` は従来の槍足軽戦闘。`--sword-battle` は素材・隊列確認用の引数と併用しない。F2で素材確認から戻る場合は直前の戦闘兵種を保持する。

## 仮ルール

既存の500対500、各軍25小組の戦闘へ刀武士を接続した。距離・向き・攻撃線の閉塞を判定し、接近、斬撃表示、損害、士気低下、小組の敗走、全体撤退を更新する。

| パラメータ | 槍足軽 | 刀武士 |
| --- | --- | --- |
| 小組中心間の攻撃距離 | 7.5 | 5.2 |
| 接近時の停止距離 | 7.2 | 4.9 |
| 表示兵士間の攻撃距離 | 3.5 | 1.5 |
| 移動速度 | 1.8 | 2.0 |
| 小組旋回速度（rad/秒） | π | 3.5 |
| 基礎損害係数 | 1.2 | 1.2 |

値は描画座標系の試作値で、史実のメートル・速度や兵種の強弱を示さない。小組の中心距離と表示兵士の間合いは別に判定する。刀は表示兵士が実際に接近できる停止距離へ調整した。

損害は既存の小組単位の時間積分で計算する。斬撃一回ごとの個体命中による損害ではない。既存の仮音を共用し、刀専用の音素材は未追加。

## 制限と次の作業

表示兵士の持ち場への追従には隊列確認の兵種別加速値（槍2.0、刀2.5）を共用する。個体差は0.85〜1.15倍、減速は加速の2倍。追従速度の上限は備の速度の1.5倍、敗走小組・撤退中の備では2倍とする。小組が移動して持ち場が遠くなっても速度が無制限に増えない。停止・初期化では追従状態も停止・初期化する。

表示兵士の旋回にも隊列確認の兵種別基準値（槍1.8、刀2.3 rad/秒）を適用した。移動方向・小組の向き・攻撃対象の向きから目標を決め、一度の更新で旋回上限を二重に使わない。対象との角度差が0.35 rad（約20度）以内になるまで攻撃表示・命中音を待つ。

移動は更新開始時の体の正面へ限定する。持ち場が背後ならその場で旋回し、正面への一致度に応じて加速する。進む距離は持ち場への正面方向の投影距離を上限とし、旋回中に持ち場から遠ざかることを防ぐ。到着判定の0.003単位以内だけ位置を合わせる。歩行表示は実際の前進がある間に行い、到着時に待機へ戻す。

表示兵士同士の簡易円コリジョンを追加した。移動後、攻撃対象の選択前に、生存者の中心間隔が0.22単位未満なら双方へ重なりの半分を補正する。完全一致時はX方向へ分離する。空間を格子に分けて近隣だけを調べ、補正は全組み合わせを集めてから適用する。一体の補正は一更新0.11単位までとし、密集時に残る重なりは次回も判定する。

この間隔は固定10,000体の表示密度に合わせた仮値で、実兵の体格や24体の隊列確認の衝突半径ではない。描画人数の1,000 / 5,000 / 10,000切り替えとは独立し、両陣営を同じ条件で判定する。死亡した兵士は補正・障害物の対象外。補正で横方向へ押されることはあるが、自力の前進方向・速度とは分けて扱う。地表の高さを補正後に取り直す。

小組の衝突・損害計算へ個体位置を書き戻す処理、24体の隊列とのコリジョンの共通化は未実装。表示更新間隔に応じた加減速・旋回・重なり補正であり、個体軌跡の固定刻みへの統合も今後の課題。連続衝突判定ではないため大きな時間刻みのすり抜けは防げず、密集時の完全な非重複も保証しない。

24体の[隊列確認](formation_drill.md)とは別の移動モデル。次は隊列の個体追従・衝突と戦闘側の小組移動の統合を進める。異兵種混成・槍対刀の描画、弓の射撃、騎馬の突撃、関ヶ原の編成への割当は未実装。接触面別の兵力配分は引き続き観察用で、損害には未反映。
