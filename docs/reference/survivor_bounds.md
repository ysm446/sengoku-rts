# 残存部隊に合わせた備の占有範囲

作成日時: 2026-09-08 09:59
更新日時: 2026-09-08 09:59

## 停滞の原因

両軍士気100・左右差なしの混成戦は、旧実装では約78秒以降に攻撃が止まった。90秒時点の非敗走小組26組はすべて目標なしで、最も近い歩兵同士でも距離28、弓から敵までは約38.4だった。歩兵の索敵範囲24、弓36から外れていた。

備同士の押し戻しが常に半幅14の矩形を使うため、前衛が敗走した後も空いた配置枠が進軍を止めていた。小組は索敵できず、備も元の進軍命令で間を詰められない状態だった。

## 修正

非敗走かつ兵力が残る小組の配置スロットの範囲に、各方向3.6の余白を加えて押し戻し用の矩形を計算する。25枠が残る場合は従来の半幅14と同じ。前方や側方の枠が空いた場合、その側の占有範囲を縮める。休息中の生存小組は含める。

矩形は配置スロットから求め、接近や回り込みの実変位は含めない。これは備の大まかな押し戻し用であり、実際の移動は従来の小組間の連続衝突検査で確認する。敗走者も実位置の障害物として残る。停止命令・移動先・索敵距離・損害係数は変更しない。接敵状態の既存の28.001判定は維持しており、今回の修正は備の全判定を実形状へ統一するものではない。

## 検証と制約

前方2列が敗走し後続が残る配置を両方向で用意し、20秒以内に攻撃を再開できること、備の移動上限と生存小組間の距離4.5以上、停止命令を検証する。

混成6戦を再測定し、陣営交換時の対応を確認した。左右差なしの配置は60.983秒で決着し、旧実装の長時間停止は再現しなくなった。標準配置の決着時間や損害も変化するため、戦闘バランスの一般的な改善とは扱わない。[比較結果](mixed_battle_endurance.md)を参照。

`mixed_battle_tests --stagnation-report` は両軍士気100・左右差なしの配置を90秒進め、非敗走小組の目標・距離・状態・変位をCSVへ出す。変更後は90秒より前に決着するため、この出力だけを戦闘中の停止の証拠として扱わない。waitとdecisionはそれぞれCombatWait、TacticalDecisionの列挙値。target=-1は目標なし、distance=-1は目標距離なし、nearest_enemy=10000は対象なしを表す。
