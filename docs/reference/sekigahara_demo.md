# 関ヶ原の史実再生デモ

作成日時: 2026-09-06 08:19
更新日時: 2026-09-06 08:22

## 目的とモードの分離

まず、関ヶ原の地形・布陣・進軍・転進・敗走を時系列で眺められるデモを作る。その後、同じ初期条件を自律シミュレーションへ渡し、史実と同じ帰結になるかを比較する。異なる結果も検証材料として扱い、勝敗を史実へ強制しない。さらに、途中時刻から命令や判断へ介入する遊び方を目指す。

今回の史実再生は作成済みの経路と時刻から状態を求める。既存の損害・接触面・士気・コリジョン計算は呼ばない。軍勢の衝突、交戦時の隊列拡張、槍突き、離脱も再生用の表現であり、シミュレーションの検証結果ではない。

## 実装したもの

- 丘陵6地点と平地、河川・街道を示す帯、森林を持つ3Dの模式地形。
- 主要14軍勢。軍勢名、陣営色、正面の帯、歩行・槍突き表示。複数の武将を集約した軍勢を含む。
- 08:00〜14:30の時間再生、停止、巻き戻し、速度切り替え、7局面へのジャンプ。
- 進軍経路が伸びる矢印と暗い移動履歴。矢印を非表示にして布陣を見ることもできる。
- 地図上の旗または一覧から軍勢を選択し、状態と説明を確認する。
- 小早川・脇坂らの転進を金色で表示。各隊の撤退を時間差で再生する。
- 俯瞰カメラの移動、拡大縮小、水平回転。北向きの方位標を地形上に表示。
- 起動時は停止した初期布陣を表示する。現段階の関ヶ原再生は無音。

軍勢の表示人数は各72体の記号的な密度で、史実兵力や損耗率を表さない。全武将・全備の配置ではない。地形は標高データを取り込んだものではなく、主要地名の相対関係を説明するための関数地形。距離の単位は仮の描画単位で、地図の縮尺・当時の川筋・街道・退路を厳密に再現していない。序盤の霧、火縄銃・騎兵の固有表現、細かな戦闘経過は未実装。

## 操作と起動

引数なし、または `--sekigahara` で起動する。右上の「戦闘試作へ」で従来の2部隊シミュレーションへ移れる。直接起動する場合は `--battle`。戦闘試作からデモへはアプリを起動し直す。

| 操作 | 内容 |
| --- | --- |
| 再生する / Space | 再生・一時停止。終了後は初期時刻から再生 |
| 最初に戻る / Home | 08:00へ戻して停止 |
| 下部タイムラインをクリック・ドラッグ | 任意の時刻へ移動して停止 |
| 右側の局面をクリック | その局面へ移動して停止 |
| ← / → | 10分戻す・進める |
| 速度ボタン | 1実秒あたり2分・6分・12分を切り替え |
| 旗・軍勢一覧をクリック | 軍勢を選択し、説明と位置の輪を表示 |
| 進軍矢印ボタン / G | 矢印の表示切り替え |
| WASD / ホイール | カメラ移動 / 拡大縮小 |
| Q・E / 中ボタンドラッグ | 水平回転 |
| 全景へ / R | 北が奥になる全景へ戻す |
| Esc | 終了 |

初期クライアント領域は1600×960。従来の戦闘試作は1920×1080を維持する。低解像度・高DPIでのUI調整、ゲームパッドや読み上げ対応は今後の課題。

## 採用した資料と推定

参照日: 2026-09-06。以下は公的施設・観光案内による通説の紹介で、一次史料の批判的検討を完了したものではない。画像や地図そのものの転載は行わず、固有名詞と大まかな経過を参照して独自の模式図を作成した。

- [関ケ原観光協会・関ケ原総合観光ガイドブック](https://www.sekigahara1600.com/download/file/20200109155213.pdf)：8時ごろの開戦、家康の本陣前進、正午ごろの小早川転進、西軍各隊の敗走という概略を参照。
- [岐阜関ケ原古戦場記念館・徳川家康コース](https://sekigahara.pref.gifu.lg.jp/tokugawa-ieyasu/)：井伊・松平の先行、桃配山からの本陣移動を参照。

史実として一意に確定した時刻表ではない。小早川の転進時刻や動機、家康の本陣移動時刻には異説・資料間の差があり、今回は一般的な紹介の筋を採用する。家康の前進開始10:30、転進12:00、西軍の崩れ12:30以降などのキーフレームは観察用の仮設定。威嚇射撃など、争いのある原因を確定イベントとして組み込まない。

笹尾山を北西、松尾山を南西、桃配山を東、南宮山を南東として配置した。黒田・竹中、加藤・田中、井伊・松平、脇坂ら、南宮山方面などは表示を簡略化するため集約している。島津の突破は概略の南東方向を示す経路で、実際の詳細な行程ではない。

## データと描画の構成

- `src/historical_scenario.h/.cpp`：軍勢、丘陵、イベント、時刻付き経路と、その時刻の状態を返す純粋なサンプル処理。戦闘・描画APIに依存しない。
- `src/historical_scene.h/.cpp`：模式地形、旗ラベル、軍勢、正面、進軍矢印を既存DX12描画へ渡す。文字はWindowsフォントからAtlasの空きタイルへ生成する。
- `src/historical_window.cpp`：タイムライン、軍勢・局面選択、カメラ、モード切り替え。

再生データは現時点ではC++の構造体による定義。外部JSON等の読み込みは未実装。巻き戻しは経過時間の逆計算ではなく、指定時刻から全表示を再生成するため履歴に依存しない。現在のAtlasに収まる軍勢数を前提にしており、合戦追加時には容量・データ検証の拡張も必要。

## 次に進める順序

1. 関ヶ原デモの見え方と操作感を確認し、実座標・標高・史料ごとの時刻の根拠を整える。
2. シナリオの初期配置を多軍勢の戦闘計算へ変換する。距離・方角・接触面・占有領域・退路を共通の地形座標にそろえる。
3. 史実再生と自律計算を同じ時刻軸で比較し、局面・敗走・勝敗の違いを観察する。史実への一致だけを成功条件にしない。
4. 一時停止した状態から介入へ分岐し、進軍命令、予備の投入、転進するかどうかなどを変更する。再生用状態だけでは兵力・士気などが不足するため、移行時の初期化規則と仮定を明記する。
5. 地形・軍勢・イベントを外部データへ移し、別の合戦を追加する。

接触面による損害・混雑・局所敗走の連鎖は、引き続き[接触面と包囲戦の方針](contact_fronts.md)に沿って発展させる。

## 検証

時刻の更新間隔への非依存、一時停止と範囲制限、転進境界、南宮山方面の待機、巻き戻し後の同一表示、Atlas範囲・Sprite数の維持を自動検証する。DX12テストでは7時点の画像を保存し、再生・停止・ドラッグでの時刻移動・初期化・軍勢選択・矢印切り替えをWin32メッセージで確認する。最初と12:15の画像には通常のUI描画を合成した確認画像も保存する。

史実の正確性や、自律戦闘による再現の成否を検証したテストではない。実マウスによる連続操作と長時間再生の手動確認は未実施。
