# 弓の射撃と混成戦闘

作成日時: 2026-09-06 14:14
更新日時: 2026-09-06 14:31

## 操作と編成

F8 / `--mixed-battle` で各軍500人の槍・刀・弓混成戦闘を開く。Spaceで進軍、Homeで編成を保って初期化。各軍は槍12小組240人、刀8小組160人、弓5小組100人。赤軍は中央三列を槍、両翼を刀にする。青軍は前二列と第三列の両端を槍、第三列の中央と第四列を刀の予備とする。弓は両軍とも最後列。開始位置と進軍先のXを赤-6・青+6にずらし、真正面で同じ兵種同士が並ぶ配置を変える。命令は既存の備単位の移動・停止を使う。任意の編成編集と弓だけの戦闘モードは未実装。

## 射撃の仮ルール

- 射程8〜36、射撃間隔3秒、飛翔速度20。射程境界36の新規目標選択は含めない。値は試作の描画座標系であり史実の距離ではない。
- 一小組の射撃参加は最大10人。斉射の損害は参加人数×0.18×士気係数。射撃に近接の接触面配分は使わず、弓は近接損害を与えない。
- 約20度以内に向き直り、備が実際に移動しておらず、帰還・交代などの経路動作中でもなく、8以内に敵がいないとき発射する。接敵中に残る移動要求フラグではなく、固定刻み前後の座標で備の停止を判定する。
- 近い有効な相手を優先する。共通地形と高さ2・半径2.25の小組近似で曲射の射線を確認する。発射前は32分割で確認し、飛翔中も毎固定刻みで地形・小組による遮蔽を確認する。味方や別の小組に遮られた矢は消え、遮った相手への損害・誤射は発生させない。
- 発射時の狙点へ放物線状に飛び、飛翔時間後にその位置から2.25以内に狙った小組がいれば着弾する。移動した敵を追尾せず、予測射撃や乱数による命中判定は使わない。実在する矢一つずつの物理計算ではなく斉射単位の近似。
- 射手が敗走しても発射済みの矢は残る。一時停止は飛翔・装填を停止し、初期化と戦闘終了で矢を消す。

## 表示

混成用Atlasを槍・刀・弓の三領域にし、小組の兵種で待機・歩行・攻撃を切り替える。発射後1秒間を弓の攻撃動作に使い、個体も向き直ってから射撃姿勢を取る。参加割合に応じた人数を上限とする。

一斉射につき三本の代表の矢を描く。描画本数や兵士表示密度は損害を変えない。着弾による死亡表示は、損害を受けた小組の狙点に近い生存兵へ反映し、近接命中を待たない。小組別の残存兵力による死亡上限を維持する。矢の専用効果音、個別の命中部位、盾、防御姿勢、厳密な連続衝突判定は未実装。
