# 兵種別の隊列確認

作成日時: 2026-09-06 08:56
更新日時: 2026-09-06 08:56

## 目的

槍足軽・刀武士・弓足軽・騎馬武者を、同じ移動命令で比較するための隊列試作。24体を4列×6段に配置し、隊列の基準位置と各兵の位置・向き・速度を別々に更新する。新兵種の自律戦闘へ進む前に、瞬間移動や一斉旋回を避けた移動を確認する。

関ヶ原の史実再生、従来の2備の戦闘計算とは独立した試験場。軍勢の階層・兵力・損害・士気とはまだ接続していない。24体は表示間引きのない移動確認用で、特定の史実編成ではない。

## 操作

関ヶ原の「兵種を見る」からF6で隊列確認へ移る。F6で元の素材確認へ戻る。直接起動もできる。

```powershell
$appPath = '.\build\Release\sengoku_rts.exe'
& $appPath --formation --unit cavalry
```

`samurai` / `archer` / `ashigaru` も指定可能。起動時は停止しており、前方に初期目的地を表示する。

| 操作 | 内容 |
| --- | --- |
| Space | 隊列更新を再生・一時停止 |
| 右クリック | 地表へ移動先を設定。停止中は命令を保持 |
| H | 基準位置をその場で止め、各兵を整列させる。停止中はSpaceで再開 |
| Home | 位置・向き・動作時計を初期化して停止 |
| F4 | 兵種を変更し、その兵種の間隔で初期化して停止 |
| F6 | 素材確認と隊列確認を切り替える |
| F2 | 従来の槍足軽の戦闘試作へ移る |
| WASD・矢印 / Q・E / 中ドラッグ / ホイール | カメラ移動 / 水平回転 / 拡大縮小 |

黄色の点が各兵の目標となる持ち場、水色の輪が隊列全体の目的地。タイトルの「隊列ずれ」は各兵から持ち場までの平均距離を示す。F3の攻撃表示は素材確認で使い、隊列確認では攻撃しない。

## 現在の仮パラメータ

値は描画座標系での比較用で、史実の速度・間隔を示すものではない。

| 兵種 | 基準速度 | 加速度 | 基準旋回(rad/秒) | 衝突半径 | 列間隔 | 前後間隔 |
| --- | --- | --- | --- | --- | --- | --- |
| 槍足軽 | 1.7 | 2.0 | 1.8 | 0.38 | 0.95 | 1.1 |
| 刀武士 | 2.0 | 2.5 | 2.3 | 0.32 | 0.8 | 0.9 |
| 弓足軽 | 1.8 | 2.2 | 2.0 | 0.38 | 0.95 | 1.05 |
| 騎馬武者 | 4.0 | 1.3 | 0.7 | 1.05 | 2.3 | 2.7 |

## 更新方式と制限

- 60Hzの固定刻みで、描画頻度と独立して更新する。
- 基準の向きを有限速度で目的地方向へ回し、その向きに合わせて各兵の持ち場を回転する。到着前に減速する。
- 個体は持ち場へ追従しながら近隣を避ける。追従の上限速度は基準の1.25倍、旋回は1.5倍。隊列の平均ずれが2.5を超えると基準位置が減速して待つ。
- 円の重なりは双方へ対称補正する。これは試作の押し戻しで、物理的な接触力・馬体の長方形占有・衝突時の加速度を再現するものではない。
- Hは基準位置の即時停止命令で、個体の追従・再整列は継続する。
- 地形は足元の高さに使う。坂の速度補正、木や地形障害物の通行判定、複数隊列の衝突、経路探索は未実装。
- 射撃、近接攻撃、突撃、追撃、戦闘中の隊列変形、軍勢の階層への統合は今後の実装。

## 検証

`formation_drill` で4兵種の進軍・途中の方向変更・到達・再整列・個体間隔・一時停止・H停止・更新頻度への非依存を確認する。円間隔には反復補正の許容誤差0.03を設ける。`dx12_formation` は騎馬の隊列を80フレームで10秒進め、途中で進路変更し、移動命令・H・Home・Spaceと描画を確認する。

`build/formation.bmp` に終了時、`build/formation.bmp.turn.bmp` に旋回中の画像を保存する。実マウス操作、長時間の混雑、複雑な命令列は未検証。
