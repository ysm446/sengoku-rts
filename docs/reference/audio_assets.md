## 制作の分担と現状

Prototypeは仮音で進められるため、ユーザーが先にすべての音を用意する必要はない。こちらではPythonなどによる波形・ノイズ合成で、短いUI音、風、足音・衝突音・太鼓風の仮効果音をWAVとして制作できる。提供された素材の切り出し、音量調整、ループ化、ゲームへの組み込みも担当できる。

自然な人声、群衆の鬨の声、実物の甲冑や法螺貝などは、録音または外部素材の調達を本素材の候補とする。現在の作業環境には専用の音声・効果音生成ツールは接続されていない。本物らしく仕上げる工程ではユーザー側の素材提供が必要になる場合があるが、自作必須ではない。

現在は風・進軍・交戦の仮音合成とゲーム内再生を実装済み。外部録音の調達、WAVの読み込み、本素材の品質調整は未実装。

## 音の方向性

原設計のAudio方針に従い、BGMより風・進軍・戦闘の空気感を優先する。近くでは草や土を踏む音、装備の揺れ、槍の衝突が分かり、遠くでは部隊全体のざわめきとして聞こえる表現を目指す。音を極端に低品質化することは、レトロな画面表現の必須条件にはしない。

初回は風と進軍音で現在の画面に音を付け、戦闘実装に合わせて衝突音を追加する。下記の種類数・長さは制作目安であり、エンジンの確定した制限ではない。

## ユーザー側で準備する場合

今すぐの必須素材はない。自然な音を先に集めるなら、まず「土・草の足音」「装備の揺れ」「草原の風」の3種類を優先する。次に木・金属の衝突、鬨の声を揃える。法螺貝・馬・火縄銃・BGMは後回しでよい。

受け渡しはWAVを基本とし、新規収録なら48 kHz / 24 bit PCMを制作目安にする。既存素材は元形式のままでよく、必要な変換はこちらで行う。個別の効果音・声はmono、広がりのある環境音はstereoを基本とする。過度な残響や音楽を混ぜず、1ファイルに1種類の音を入れる。ループ素材は継ぎ目を意識し、未加工の原音も保存する。

配置先は`assets/audio/`を予定する。素材ごとに出典、制作者、利用条件、改変の有無を`assets/audio/credits.md`へ記録する想定。ゲームへの組み込みと配布が可能な素材を選ぶ。現時点ではこのフォルダとクレジットファイルは未作成。

## 組み込み時の方針

- 全兵士の足音を同時に鳴らさず、Formationごとに代表的な足音と装備音を間引いて再生する。停止した部隊の進軍音は止める。
- 同じ音の連続感を減らすため、複数素材と小さな音量・再生速度の変化を使う。
- カメラ回転後も画面上の左右と音の定位を合わせ、距離とZoomに応じて部隊音の聞こえ方を調整する。
- 環境音、部隊・戦闘音、UI音の音量を分ける。同時再生数に上限を設け、密集時の過大音量を防ぐ。
- ループの継ぎ目、開始・停止時のノイズ、左右定位、一時停止と再開、密集時の音量を実機で試聴して確認する。

## 実装済みの仮音

src/audio.cppで48 kHz / 16 bit / monoの風・足音＋装備の擦れ（各8秒）と衝突（0.25秒）の3波形を起動時に合成する。固定シードのノイズと減衰する正弦波を使ったプロジェクト内の仮素材であり、外部録音・生成サービスは使っていない。WAVファイルは同梱せず、PCMをメモリに保持する。

XAudio2の再生数は風1＋各備の進軍2＋交戦2の計5に固定。兵士ごとの音は重ねず、固定個体集合の生存兵士に歩行があるかで進軍音量を決める。衝突音は槍突きの最大伸長コマを通過した命中通知で単発再生する。兵士の表示人数を増やしても音量は増えない。両軍で再生速度を少し変え、通常の動作切り替えは音量を滑らかに追従させる。衝突音は陣営ごとに0.25秒以上の間隔を空け、同時刻の複数命中は代表1音へ間引く。再生中は追加バッファを積まない。死亡を伴わない命中でも鳴る。

カメラの右方向への投影で左右定位を決め、カメラ注視点からの距離とZoomに応じて音量を減衰させる。進軍音は備中心、衝突音はその陣営で最後に通知された命中相手の位置を音源とする。独立移動する各小組の足音定位は今後の作業。Mで消音切り替え。一時停止・素材確認・別ウィンドウへの切り替え・最小化時は即座に消音する。風・進軍ループの再生位置は無音中も進む。単発音は停止・破棄し、消音中の命中通知も消費するため再開時に過去の音をまとめて再生しない。

音声出力が利用できない場合もゲームは無音で続行し、タイトルに「音声出力なし」と表示する。描画の自動テストでは音声デバイスを開かない。専用の音声テストはデバイスを無音で初期化し、利用不可ならその状態を報告して波形・ミックスの検証を行う。デバイス切り替え・切断後の自動復旧は未検証。

Debug / Releaseの各8テストが成功し、この環境では音声デバイスの初期化も成功した。実際の試聴による音量・ループ感・開始停止ノイズの評価は未実施。自然な足音・甲冑・人声・BGMは引き続き後続工程。

API参照：[XAudio2のバッファ投入とデータ寿命](https://learn.microsoft.com/en-us/windows/win32/api/xaudio2/nf-xaudio2-ixaudio2sourcevoice-submitsourcebuffer)。

## ゲーム内の音量調整

F5で全体→環境→効果音の順に調整対象を選び、＋／－（テンキーも可）で10％ずつ変更する。範囲は0〜100％で、初期値は各100％。タイトルに対象と値を表示する。全体音量を各音へ乗算し、環境は風、効果音は足音・装備の擦れ・衝突へ適用する。定位や再生頻度は変更しない。

M消音・Space一時停止・Home初期化・素材切り替えでも値を維持する。音量変更時に実行ファイルと同じフォルダのaudio-settings.txtへ保存し、次回起動で読み込む。消音状態と調整対象は保存しない。キーボードの押しっぱなしによる連続変更は行わない。

Debug / Releaseの各8テストが成功。音量系統の独立性と上下限、定位を変えないことを確認した。実際の聴感による最適な初期値の評価は未実施。

### 音量設定の保存

形式はバージョン1と全体・環境・効果音の整数値。書き出し完了後に一時ファイルから置換する。欠損・未知バージョン・範囲外の値・余分な文字がある場合は読み込まず初期値を使う。保存不可でもゲームは続け、タイトルに「音量保存失敗」を表示する。自動描画テストは利用者の設定ファイルを読み書きしない。
