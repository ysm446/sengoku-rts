作成日時: 2026-09-05 11:05

## 制作の分担と現状

Prototypeは仮音で進められるため、ユーザーが先にすべての音を用意する必要はない。こちらではPythonなどによる波形・ノイズ合成で、短いUI音、風、足音・衝突音・太鼓風の仮効果音をWAVとして制作できる。提供された素材の切り出し、音量調整、ループ化、ゲームへの組み込みも担当できる。

自然な人声、群衆の鬨の声、実物の甲冑や法螺貝などは、録音または外部素材の調達を本素材の候補とする。現在の作業環境には専用の音声・効果音生成ツールは接続されていない。本物らしく仕上げる工程ではユーザー側の素材提供が必要になる場合があるが、自作必須ではない。

現在は素材リストの作成段階で、音声ファイルの制作・調達とゲーム内再生は未実装。

## 音の方向性

原設計のAudio方針に従い、BGMより風・進軍・戦闘の空気感を優先する。近くでは草や土を踏む音、装備の揺れ、槍の衝突が分かり、遠くでは部隊全体のざわめきとして聞こえる表現を目指す。音を極端に低品質化することは、レトロな画面表現の必須条件にはしない。

初回は風と進軍音で現在の画面に音を付け、戦闘実装に合わせて衝突音を追加する。下記の種類数・長さは制作目安であり、エンジンの確定した制限ではない。

## ユーザー側で準備する場合

今すぐの必須素材はない。自然な音を先に集めるなら、まず「土・草の足音」「装備の揺れ」「草原の風」の3種類を優先する。次に木・金属の衝突、鬨の声を揃える。法螺貝・馬・火縄銃・BGMは後回しでよい。

受け渡しはWAVを基本とし、新規収録なら48 kHz / 24 bit PCMを制作目安にする。既存素材は元形式のままでよく、必要な変換はこちらで行う。個別の効果音・声はmono、広がりのある環境音はstereoを基本とする。過度な残響や音楽を混ぜず、1ファイルに1種類の音を入れる。ループ素材は継ぎ目を意識し、未加工の原音も保存する。

配置先は`assets/audio/`を予定する。素材ごとに出典、制作者、利用条件、改変の有無を`assets/audio/credits.md`へ記録する想定。ゲームへの組み込みと配布が可能な素材を選ぶ。現時点ではこのフォルダとクレジットファイルは未作成。

## 組み込み時の方針

- 全兵士の足音を同時に鳴らさず、Formationごとに代表的な足音と装備音を間引いて再生する。停止した部隊の進軍音は止める。
- 同じ音の連続感を減らすため、複数素材と小さな音量・再生速度の変化を使う。
- カメラ回転後も画面上の左右と音の定位を合わせ、距離とZoomに応じて部隊音の聞こえ方を調整する。
- 環境音、部隊・戦闘音、UI音の音量を分ける。同時再生数に上限を設け、密集時の過大音量を防ぐ。
- ループの継ぎ目、開始・停止時のノイズ、左右定位、一時停止と再開、密集時の音量を実機で試聴して確認する。
