# 編成の4階層

作成日時: 2026-09-05 12:15
更新日時: 2026-09-07 01:05

ユーザー指定の人数目安をゲーム設計として採用する。史実上の固定編制を定義する資料ではない。

| 階層 | 人数の目安 | ゲーム上の役割 |
| --- | --- | --- |
| 小組 | 10〜20人 | 接敵・待機・追従を扱う最小集団 |
| 組 | 50〜100人 | 槍組・鉄砲組など兵種のまとまり |
| 隊 | 200〜500人 | 武将配下の実戦部隊 |
| 備・軍勢 | 500〜2,000人以上 | プレイヤーが主に命令する単位 |

## 今回の実装

既存のFormationを500人の備として扱い、左右クリック・Hの命令先を維持する。各備の内訳は20人の小組25個、100人の組5個、300人と200人の隊2個。`src/organization.h`で所属と編成人数を保持する。将来の可変編制や兵種混成は未実装。

小組は5×5の区画に配置し、区画内の間隔を詰めることで小組間に隙間を設ける。兵士の固定IDから小組を決め、表示密度の変更でも所属は変えない。表示用IDは引き続き各陣営5,000であり、編成上の20人と描画人数は別。表示人数を変えても編制人数は増えない。

部隊Simulationの固定更新で、小組ごとに待機・前進・交戦・撤退状態を更新する。備の移動・撤退を引き継ぐ。小組は標準配置からの変位と目標変位を持ち、備が停止していても独立して進める。小組中心間の直線距離7.5以内を接敵とし、攻撃には向きと遮蔽も判定する。備の接触領域外でも近い小組同士は戦える。前方5小組が接敵し、前から2列目の左右端2小組は外側へ進む。他の18小組は待機する。

表示側の攻撃は従来どおり個々の前列・敵との距離から決める。欠員補充は各小組内に限定し、後ろの小組から所属を越えて一列に詰めない。倒れた兵士の位置は保持する。小組の接敵状態は集団の概略、個体の射程判定は実際に槍突きを表示する条件として区別する。

## 回り込みの試作経路

敵方向の主軸をXまたはZから選ぶ。左右にずれた布陣でも両翼の経路を使う。左右端の小組は最低6.1横へ移動し、敵の同じ側の端がさらに外にある場合はその差も加えてから敵方向へ前進する。最初の前から2列目は最大12、交代で使う後方小組は元の列から同じ前進先までの距離を目標にする。途中で接敵したら停止する。両軍が同じ動きをするため、初期デモでは側方へ出た小組同士が接敵する。相手の現在の向きに対する側面・背後の攻撃補正を追加した。包囲全体の判定は未実装。

同じ固定刻みの開始位置から通行可否を判定する。小組中心の間隔4.5と双方の移動余裕を確保できない場合は待機し、地形端では小組中心を±76以内に収める。障害物を迂回する経路探索や、兵士一人ずつの衝突解決ではない。

Hは回り込みも中断し、次のMoveで再び許可する。Spaceの一時停止中は進まない。離脱・撤退・勝敗確定後は独立前進を止め、外側の通路を元の列まで後退してから横へ戻る。備の移動中も備に対する変位を徐々にゼロへ戻す。Hは復帰も停止する。勝敗確定時は勝者にも復帰を許可する。Homeは変位と目標を初期化する。各小組の現在の仮中心±2.6から選択し、該当する小組がなければ従来の備中心±14で備を選ぶ。回り込み中の小組からも本隊へ命令できる。

## 次の段階

- 正面中央3小組の交代、斜め接触や障害物に対応する経路。
- 組の兵種、隊の武将、備の指揮命令を下位へ伝えるルール。
- 組・隊の指揮官や関係に応じた士気伝播。現在は小組士気の平均と敗走数を備へ集計する簡易方式。
- 隊・組単位の選択UI。小組の所属と状態はタイトルに表示済み。

両翼の帰還・予備選択には小組の残存兵力と士気も使う。交代対象は回り込みに出た両翼と正面列の両端であり、正面5小組の一斉交代ではない。

## 疲労と両翼の交代

小組の疲労は接敵1秒で1増加し、標準位置で非接敵なら1秒で0.5回復する（0〜30）。兵力や士気とは別の試作値で、損害・勝敗への補正には使わない。疲労8に達した回り込み小組は帰還を開始し、帰還中は回復しない。疲労2以下の非接敵の後方小組から、前寄りのものを次の予備として選ぶ。表示Sprite数を参照しない。

経路は外側への移動・前進・復帰を保持する。復帰では前進分を先に戻してから横移動し、帰還が完了するまで同じ側へ予備を出さない。接敵方向が変わった場合も、保存した経路の軸に沿って復帰する。通路が塞がれると待機し、迂回や強制移動はしない。Homeで疲労と経路状態も初期化する。

復帰中の表示兵士は攻撃より移動を優先するが、前列・射程の条件を満たせば敵の命中対象になりうる。帰還しても死亡者を復活させず、死体の位置も変更しない。

## 正面両端の交代

前列両端の生存小組が疲労8以上・兵力半分以下・士気30以下のいずれかになった場合、直後の区画にいる疲労2以下・兵力半分超・士気30超の小組を予備に選ぶ。条件を満たす回り込み中の小組も転用する。同じ側の通路が他の経路で予約されていれば開始しない。

1. 予備が外側6.1の通路へ退避する。前進済みなら外側を元の後列まで戻る。
2. 後列が空いてから、前列小組が5.2後退する。
3. 予備が外側の通路を前列の高さまで5.2前進する。
4. 予備が横へ入り、両者の配置区画を交換して交代を終える。

移動は従来の小組間隔・地形端の判定で待機できる。中央3小組の間を通り抜ける経路はない。途中では交代参加者の攻撃を止めるが、敵の命中対象にはなりうる。所属する組・隊、小組ID、兵力・士気・疲労、死亡位置を保持し、配置区画だけを交換する。疲労回復は完了後の非接敵時に行う。

Hは交代移動を停止し、Moveで再開する。Spaceは全体を一時停止する。離脱・敵方向変更・勝敗確定後も予約済みの軸と順序で交換を完了し、交換後の配置を維持する。途中で消耗しても予備を差し替えず、通路が塞がれれば待機する。参加者が敗走した場合は交代予約を解除し、残った相方を復帰させる。Homeで予約と区画を初期化する。

## 局所敗走と連鎖

小組の士気20以下、または残存兵力が編成兵力の25%以下で敗走する。交代のための後退とは別状態で、Home以外では復帰しない。敗走開始から8秒間、現在の小組中心から半径8以内にいる同じ備の非敗走小組の士気を、動揺源1小組につき毎秒6下げる。同じ刻みで発生した敗走は次の刻みから波及し、同一刻みで再帰的に全体へ広がらない。範囲は小組中心のXZ平面での実距離を使い、境界の8を含む。敗走者の逃走位置と受け手の接近・迂回・交代変位を反映する。範囲を出ると影響が止まり、動揺源が有効な間に再び近づけば影響を受ける。個別Sprite間の距離や視線の遮蔽は扱わない。

小組は敗走開始時の敵と反対方向へ通常の1.5倍速で離れ、中心を世界座標±74以内に制限する。Move／Hは敗走者を引き戻さず、備の移動や撤退にも連れ動かさない。Spaceで停止する。攻撃・被害配分・予備選択から除外し、追撃は未実装。敗走者も小組の通行判定へ含め、空いた方向へ局所回避し、退路が塞がれれば停止する。出口が開くと再開する。備全体の命令移動・撤退・押し戻しも、小組との衝突で止まり、命令先を保持して再開を待つ。備単位でも後退・横移動・通過・目的地へ復帰する簡易迂回を試みる。候補が塞がれていれば待機する。死体の世界座標は保持する。

25小組中13小組が敗走すると備全体に撤退を命じ、勝敗を確定する。残った小組は備とともに退き、既に逃げた小組は独自の退路を維持する。初期化は所属区画・士気・敗走状態・動揺の残り時間をすべて戻す。

## 小組の選択と状態確認

左クリックした小組の所属する備を選び、その小組を明るく強調する。タイトルの先頭付近に赤／青の備・隊・組・小組番号と、待機／前進／交戦／復帰／撤退／前列交代中／交代後退中、疲労値を表示する。選択は所属IDを保持するため、移動・交代中も同じ小組を追う。右クリックとHは引き続き備全体への命令。空き地クリック・Homeで選択を解除する。

判定はSimulationの仮中心であり、個々のSpriteの輪郭や生存数を使うものではない。疲労は0〜30の試作値であり、兵力損害とは区別する。

## 小組の兵力・士気

初期兵力は各20。小組士気の初期値は備に合わせて赤100・青85。固定更新で小組ごとの敵・距離・向き・遮蔽を同じ時点から求め、攻撃できる小組の損害候補を選択相手へ適用する。相手の残存兵力を上限とする。小組が全滅しても余った被害を後列へ流さず、備の兵力も実際の配分量だけ減らす。備士気は小組士気から集計する。

小組士気は被害1につき2、接敵1秒につき0.5低下し、下限0。兵力・士気の自動回復はまだない。回り込み中に兵力が編成人数の半分以下、または士気30以下になった小組は帰還する。同じ条件の小組は次の予備に選ばない。正面両端は直後の予備との交代にも同じ消耗条件を使う。

小組の兵力・士気は表示Spriteから独立する。死亡表示の割当上限は小組別の残存兵力割合から求める。命中対象が足りない場合は無傷の小組や後列へ死亡を流さず、実兵力と表示死亡数には差が残る。攻撃係数は攻撃する小組の兵力・士気と備の隊列から求める。備士気は敗走小組を0として25小組の平均を取る。備の総兵力には逃走中の生存者も含め、敗走を死亡として減算しない。

## 左右にずれた布陣での展開（2026-09-07 01:05）

F8の中心差12でも左右端の健全な予備を横へ出す。弓・休息中・敗走中・標準位置から離れている小組は対象外とし、同じ側に別の経路がある間は次を出さない。展開先が地形外、他の小組や中央交代の予約通路に重なる場合は停止する。全後列を一斉に横へ広げる動作ではない。選択タイトルへ「側方へ展開中」「側面へ前進中」を表示する。

騎馬を含む通常の迂回では、敵へ向き続ける代わりに現在の中継点へ向き直す。これにより騎馬の旋回待ち条件と迂回方向が食い違って停止する問題を修正した。

flank_deploymentで両軸・両方向・両陣営・左右差±12の16条件における両翼の展開、味方との間隔、停止、初期化、更新間隔の一致を検証。標準混成配置の展開と弓の除外も確認する。敵が進入して塞がれた通路の再探索、備全体の幅の変更は今後の課題。
