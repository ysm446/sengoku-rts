# 前線交代・休息と全体撤退

作成日時: 2026-09-06 14:45
更新日時: 2026-09-07 00:36

ユーザーの「消耗した前衛が一度引き、予備が前進する。全体が消耗してから撤退を検討する」という希望に合わせ、既存の前線両端の交代を維持した。交代開始を兵力50%以下→75%以下、士気30以下→50以下へ早めた。疲労条件は8のまま。左右にずれた備でも交代を検討し、衝突・経路条件は維持する。弓を近接の交代予備や回り込みへ出さない。

交代して後方へ下がった小組は休息し、敵から10以上離れ、直近3秒間被害がなく、周囲の敗走による動揺がなければ士気を毎秒3回復、疲労を追加で毎秒1回復する。士気70以上・疲労2以下で休息を終える。兵力は回復しない。交代後退中・休息中は士気10超かつ兵力25%超なら、士気20以下になっただけで敗走しない。

複数の敗走源から同時に受ける動揺は合計毎秒6までに制限。全体撤退は「敗走13小組以上」「戦力に余裕のある小組が5以下」が6秒続いてから確定する。余裕とは非敗走・非休息で、兵力50%超、士気40超、疲労8未満。状態が改善した場合は検討時間を毎秒2戻す。画面タイトルへ余裕のある小組数と全体撤退の検討状態、選択小組へ再集結中の表示を追加した。

中央三列も隣列の空間が空いている場合に交代できる。標準位置に揃った列を横へ移して通路を作る処理も追加した。全軍で一時後退して再布陣する動作、プレイヤーへの撤退選択UIは未実装。休息完了は後方での待機復帰であり、全員が必ず前線へ戻れることを保証しない。

## 中央三列の交代（2026-09-07 00:01）

中央三列の前衛と直後の予備にも既存の消耗・適性条件を適用する。両者が標準位置にいる場合に、左右へ5.2離れた隣列の通路を確認する。中央は左側を先に、左右寄りの列は外側を先に試し、塞がれていれば反対側を試す。

予備の横移動、前衛の後退、予備の前進、予備の横移動で前列へ入る4区間を、両軍の実位置と地形端で事前検査する。予約後は他の通常移動中の味方が通路へ進入するのを抑える。敵や敗走者の進入には通常の衝突判定で停止する。中央は各備で同時に1組までとし、両端の交代は既存の2枠を維持する。

通路がない間は交代予約を作らず、前衛をその場に残す。通常の戦闘や接敵移動は継続する。通路が開いて条件を満たせば再評価する。完了時には配置枠だけを交換し、所属・兵力・表示IDは維持する。後退した前衛は休息へ入る。停止命令、一時停止、敗走・戦闘終了時の予約解除、初期化は既存の交代処理を使う。

空いた隣列がない場合は以下の列移動を試す。接敵移動で標準位置から離れた小組の交代経路、敵に塞がれた経路の再探索は後続課題。
## 密集時の通路確保（2026-09-07 00:36）

中央交代の経路が塞がれている場合、使用する側の列を外側へ6.1移して通路を作る。移動候補はその側の端までの全行の小組。標準位置に揃い、敗走・休息・別の経路行動がない場合だけ採用する。外側の列から順に移し、全員の移動完了後に既存の4段階の交代へ進む。交代後は内側の列から戻す。列移動は小組の移動速度と通常の衝突判定を使用し、位置や所属を瞬間的に入れ替えない。

移動先までの経路を両軍の占有位置と地形端で検査する。準備と復帰を含めて中央の予約を保持し、別の中央交代を重ねない。通路を作る小組はReliefCorridorとして近接攻撃・射撃を止め、選択タイトルに「交代通路を確保・復帰中」と表示する。前衛と予備は通路の準備完了を待つ。命令停止・一時停止は列移動も止める。

前衛または予備の敗走、戦闘終了、接敵解除や主軸・方向の変更では予約を解除し、通路を作っていた生存小組は通常の復帰へ切り替える。既に標準位置にいる小組は待機へ戻る。敵・敗走者の進入で詰まった場合は通過を強制しない。

準備中は攻撃参加が減り、被害で交代自体が失敗する場合がある。経路テストの完了条件は敵の占有領域を保ち攻撃参加を解除した配置で確認する。実戦での交代成功率や戦力配分の調整、手動操作による見やすさの評価は未実施。
