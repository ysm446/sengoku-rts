# 前線交代・休息と全体撤退

作成日時: 2026-09-06 14:45
更新日時: 2026-09-08 09:26

ユーザーの「消耗した前衛が一度引き、予備が前進する。全体が消耗してから撤退を検討する」という希望に合わせ、既存の前線両端の交代を維持した。交代開始を兵力50%以下→75%以下、士気30以下→50以下へ早めた。疲労条件は8のまま。左右にずれた備でも交代を検討し、衝突・経路条件は維持する。弓を近接の交代予備や回り込みへ出さない。

交代して後方へ下がった小組は休息し、敵から10以上離れ、直近3秒間被害がなく、周囲の敗走による動揺がなければ士気を毎秒3回復、疲労を毎秒1回復する。士気70以上・疲労2以下で休息を終える。兵力は回復しない。交代後退中・休息中は士気10超かつ兵力25%超なら、士気20以下になっただけで敗走しない。

## 危険な休息場所からの移動

休息中に非敗走の敵が10未満へ近づくか、動揺を伝える味方敗走兵が8以内へ入ると、安全な休息場所を探す。最寄りの脅威から離れる方向と左右45度・90度について、距離6.1と10の候補を試す。到達点は敵から12以上、動揺中の敗走兵から10以上離れ、地形内にあることを要求する。

経路全体の敵味方の占有と到達点の交代予約を確認し、旋回してから速度上限内で移動する。移動中も候補の安全性と占有を再確認し、次の位置が交代予約へ入る場合は止まる。安全な候補がなければその場で再評価する。休息場所への移動中と備の行軍中は回復せず、安全な場所で停止してから既存の回復条件を使う。兵力は回復しない。

選択タイトルに「安全な休息場所へ移動中」「休息場所への退路閉塞」を表示する。停止命令・一時停止で移動を止め、移動命令は休息先への自律移動より優先する。複数の中継点を使う経路探索は未実装。

敵の接近と味方の敗走を左右両方向から与える4条件で、移動から休息完了まで検証した。移動量、占有との距離4.5以上、停止・一時停止、更新間隔、兵力維持も確認した。標準混成戦では休息中の前衛の敗走を回避できたが、決着までの休息完了・再投入は未達。詳細は[測定結果](mixed_battle_endurance.md)を参照。

## 休息後の帰還と再参加（2026-09-07 05:16）

休息先への退避を恒久的な配置変位としていたため、敵から16以上離れた歩兵が回復後も退避先に残るケースを確認した。退避量を既存の一時的な接近変位へ記録するよう修正し、休息完了後は通常の帰還・接近処理へ引き継ぐ。位置を瞬間的に戻したり、歩兵の接近範囲を広げたりはしない。

接近できる敵がいなければ休息前の予備位置へ戻り、帰還途中で敵が通常の接近範囲に入れば索敵目標へ接近する。停止命令と既存の衝突・交代予約を維持する。通路が塞がっていれば帰還や再参加が止まることはある。

左右両方向で距離9.95の敵から退避し、回復後に再び攻撃可能になることを検証した。変更前は接近範囲外で停止して失敗し、変更後は15秒以内に再参加した。敵と敗走兵からの退避4条件では、敵がいない場合の元位置への帰還と回復後の停止命令も確認した。標準混成戦など既存の6戦の測定値は変更前と一致し、これらの戦闘での休息完了・再投入はまだ0件。

## 疲労と攻撃効率

ユーザーの休憩による回復の希望を受け、既存の疲労を攻撃効率へ反映した。疲労0で100%、8で84%、20以上で60%。計算は `1 - 0.02 * clamp(fatigue, 0, 20)`。疲労の記録上限は従来の30。槍・刀・騎馬の通常攻撃、騎馬の突撃追加損害、弓の一斉射撃に同じ係数を掛ける。参加兵数や兵力には掛けない。弓は発射時の効率を矢へ記録し、飛行中の回復で着弾損害が変わらないようにする。

接敵状態では毎秒1の疲労を蓄積し、休息中・騎馬離脱／再集結中はこの蓄積を止める。実際の突撃命中と一斉射撃にそれぞれ疲労2を加える。複数の相手へ同時に突撃しても同じ刻みでは1回分。数値は試作の調整値で、史実上の実測値ではない。

休息・騎馬の再集結では上記の安全条件を満たすと毎秒1回復する。通常の安全な待機は毎秒0.5で、備が停止・小組が待機・経路行動なし・攻撃していない場合に限る。歩兵は遠方の敵を索敵していても安全なら休めるが、弓は目標を保持している間の射撃待ちを休憩と扱わない。以前の通常回復と休息回復の重複を解消した。移動中・近くに敵がいる・被害直後には回復しない。

小組の選択タイトルへ「攻撃効率N%」を表示する。疲労が下がれば効率が戻り、欠員はそのまま残る。Spaceで疲労と回復を停止し、Homeで初期化する。今回の第一段階は攻撃効率で、疲労による移動速度の変化は後続とする。

複数の敗走源から同時に受ける動揺は合計毎秒6までに制限。全体撤退は「敗走13小組以上」「戦力に余裕のある小組が5以下」が6秒続いてから確定する。余裕とは非敗走・非休息で、兵力50%超、士気40超、疲労8未満。状態が改善した場合は検討時間を毎秒2戻す。画面タイトルへ余裕のある小組数と全体撤退の検討状態、選択小組へ再集結中の表示を追加した。

中央三列も隣列の空間が空いている場合に交代できる。標準位置に揃った列を横へ移して通路を作る処理も追加した。全軍で一時後退して再布陣する動作、プレイヤーへの撤退選択UIは未実装。休息完了は後方での待機復帰であり、全員が必ず前線へ戻れることを保証しない。

## 中央三列の交代（2026-09-07 00:01）

以下は標準配置の交代経路。接敵変位がある場合には後述の実位置の経路も使用する。

中央三列の前衛と直後の予備にも既存の消耗・適性条件を適用する。両者が標準位置にいる場合に、左右へ5.2離れた隣列の通路を確認する。中央は左側を先に、左右寄りの列は外側を先に試し、塞がれていれば反対側を試す。

予備の横移動、前衛の後退、予備の前進、予備の横移動で前列へ入る4区間を、両軍の実位置と地形端で事前検査する。予約後は他の通常移動中の味方が通路へ進入するのを抑える。敵や敗走者の進入には通常の衝突判定で停止する。中央は各備で同時に1組までとし、両端の交代は既存の2枠を維持する。

通路がない間は交代予約を作らず、前衛をその場に残す。通常の戦闘や接敵移動は継続する。通路が開いて条件を満たせば再評価する。完了時には配置枠だけを交換し、所属・兵力・表示IDは維持する。後退した前衛は休息へ入る。停止命令、一時停止、敗走・戦闘終了時の予約解除、初期化は既存の交代処理を使う。

空いた隣列がない場合は以下の列移動を試す。接敵移動で標準位置から離れた小組の交代経路、敵に塞がれた経路の再探索は後続課題。
## 密集時の通路確保（2026-09-07 00:36）

中央交代の経路が塞がれている場合、使用する側の列を外側へ6.1移して通路を作る。移動候補はその側の端までの全行の小組。標準位置に揃い、敗走・休息・別の経路行動がない場合だけ採用する。外側の列から順に移し、全員の移動完了後に既存の4段階の交代へ進む。交代後は内側の列から戻す。列移動は小組の移動速度と通常の衝突判定を使用し、位置や所属を瞬間的に入れ替えない。

移動先までの経路を両軍の占有位置と地形端で検査する。準備と復帰を含めて中央の予約を保持し、別の中央交代を重ねない。通路を作る小組はReliefCorridorとして近接攻撃・射撃を止め、選択タイトルに「交代通路を確保・復帰中」と表示する。前衛と予備は通路の準備完了を待つ。命令停止・一時停止は列移動も止める。

前衛または予備の敗走、戦闘終了、接敵解除や主軸・方向の変更では予約を解除し、通路を作っていた生存小組は通常の復帰へ切り替える。既に標準位置にいる小組は待機へ戻る。敵・敗走者の進入で詰まった場合は通過を強制しない。

準備中は攻撃参加が減り、被害で交代自体が失敗する場合がある。経路テストの完了条件は敵の占有領域を保ち攻撃参加を解除した配置で確認する。攻撃有効の固定96条件を[測定](central_relief_combat.md)し、予備の敗走と列の復帰中断を確認した。通常起動からの成功率、戦力配分の調整、手動操作による見やすさの評価は未実施。
## 実位置からの交代（2026-09-07 04:38）

接敵移動で標準位置を離れた前衛と予備にも、実際の位置を起点とする交代経路を追加した。元の前列・直後の列の配置スロットから前衛と予備を選び、消耗・士気・兵力・予備適性の既存条件を使う。双方が通常経路で、騎馬の離脱／再集結中でない場合に限る。他の交代予約がある間は新しい実位置の交代を始めず、実位置の交代中も別の交代を重ねない。

前衛が予備より敵方向に小組間隔以上離れ、両者の距離が16以内なら、中央は左右5.2、両端は左右6.1の通路を試す。予備の横退避、前衛の実位置から予備の元位置への後退、予備の側方前進、前衛の元位置への横移動の4段階で進める。全区間について敵味方の占有、段階ごとに静止している相方との間隔、地形端を事前検査する。開始後も衝突を調べ、他の味方による予約領域への進入を抑える。

位置は備中心からの相対座標で保持する。開始時は接敵変位を経路変位へ移し、世界上の位置を保つ。完了時は配置スロットを交換し、新しいスロットからの変位を計算し直して位置を引き継ぐ。前衛は予備の元位置で休息に入り、兵力・所属を維持する。HとSpaceは移動を停止し、相方の敗走・接敵解除・方向変更・戦闘終了で予約を解除する。

標準の混成戦では交代完了・休息入りが0件から1件になった。士気を揃えた条件では0件のままで、全条件で休息完了・再投入は未達。[比較測定](mixed_battle_endurance.md)を参照。今回の経路は既に空いた通路を使う段階で、移動した列全体を押し広げる処理や、実際の最前線から別の予備を探す選択までは追加していない。

## 移動済みの隣列による通路確保（2026-09-08 09:26）

実位置からの中央交代で左右の空き通路がない場合、隣列から外端までの生存小組を6.1外側へ移す候補を追加した。各小組に接近・経路変位が残っていても、通常経路で非敗走・非休息、騎馬の離脱／再集結中でなければ候補にする。前衛・予備の適性、前後間隔、距離16以内、他の交代予約との排他条件は維持する。

外側の列から順に動かす時点の占有を検査し、移動後の小組位置を使って交代の全4区間を確認する。敵や移動できない味方を無視して通路を作らない。通路確保中は前衛・予備を待機させる。小組の接近変位を位置が変わらないよう経路変位へ移し、開始時の横変位を個別に記録する。交代完了後は内側の列から戻し、開始時の実位置へ復旧する。移動中も衝突判定を適用する。

停止・一時停止で通路移動を止め、前衛・予備の敗走や接敵解除などでは既存の予約解除と通常帰還を使う。開始後の敵・味方の進入で通路が塞がれば停止する。複数中継点への再探索や別の予備選択は未実装。

両軸・両方向・両陣営で空き通路あり／なしの16条件を検証した。密集条件は前衛1.5・予備0.5の前進に加え、他の味方へ前後0.3・横0.15の接近変位を与え、交代から通路復旧まで確認する。移動量、敵味方との距離4.5以上、交換後の位置、停止・一時停止、予備敗走時の解除、更新間隔を確認した。個別の経路検証では敵の占有を維持し攻撃参加を解除する。攻撃有効の混成6戦は変更前と同じ結果で、士気100の条件の交代0件は解消していない。

## 実位置の交代の検証

両軸・両方向・両陣営の8条件で、前衛を1.5、予備を0.5前進させた配置から予約・交代・休息入りまで確認する。各刻みの移動上限、敵味方との距離4.5以上、交換後の実位置、停止・一時停止、予備敗走時の予約解除、更新間隔も検証する。経路を単独評価するケースでは既存テスト同様、敵の占有を保って攻撃参加を解除する。混成戦の比較測定では攻撃を有効にする。

`fatigue_combat`で4兵種の損害低下と60%の下限、突撃の疲労と損害、休息の回復速度・二重回復の抑止・兵力維持、休息後の同条件での攻撃効率復帰、敵の近接・被害直後の回復抑止、弓の発射時の効率、一時停止・初期化・更新間隔を確認する。

`recovery` で健全な残存12小組があれば13小組の敗走だけでは全体撤退しないこと、消耗状態の継続と改善、一時停止、回復による再参加、兵力が回復しないこと、被害直後の回復抑止、初期化を検証する。既存の交代テストでは士気18での交代継続と士気10での敗走、予備への交代、所属・兵力・位置と衝突を確認する。戦闘描画は80秒以内の赤勝利を必須にせず、交戦・局所敗走と、決着した場合の全体撤退を確認する。
