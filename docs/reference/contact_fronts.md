# 接触面・兵力配分・包囲戦の設計方針

作成日時: 2026-09-05 22:36
更新日時: 2026-09-06 13:55

## 複数相手への接続（2026-09-06 13:55）

各面の参加人数を相手別に合算し、距離・攻撃線が有効な相手すべてへ同時に損害を与える。配分は一度だけ求め、攻撃できない相手の割当を同じ刻みで他へ上乗せしない。面の幅・配置済み人数・残存兵力の上限を維持する。`activeOpponents` は相手別、`activeFighters` は合計。選択タイトルに攻撃対象の小組数も表示する。

主対象 `attackTarget` は接近・旋回の目標として残す。主対象への向きが約60度以内になり、射程と攻撃線を満たしてから他面も攻撃する近似。側背面へ配置済みの兵はその面の敵に対応できるが、面内の個別配置・隊列全体の旋回時の再配置時間はまだ計算しない。

表示は相手ごとに生存表示人数×参加人数/残存兵力を切り上げた上限を使い、前列・個体の射程・向きも確認する。同じ表示兵を二重に攻撃させない。整数化と前列の配置制約があるため、実参加人数との厳密な一致は保証しない。死亡表示は既存の小組別損害上限を保つ。以下の一対象のみという記録は旧段階の仕様。

## 現在の接続範囲（2026-09-06 13:21）

配置済み兵力を実際の損害へ接続した。各面で `min(配置済み人数, 接触幅 / 0.9)` を参加上限とし、相手別の接触幅の比で割り当てる。全参加人数を残存兵力以内に制限し、現行の攻撃対象に割り当てられた人数だけを損害に用いる。正面幅4.5の一列5人を基準とし、従来の `残存兵力 / 20` を `攻撃参加人数 / 5` に置き換えた。予備を増やしても同じ幅からの損害は増えない。配置は毎秒2人の既存処理で進み、未配置の予備は即攻撃しない。

対象までの距離、向き、攻撃線の閉塞、帰還・交代中の攻撃抑止は維持する。選択タイトルの「面配置 現在→目標」と「攻撃参加」で状態を確認できる。参加人数は直前の損害計算時の値。個別兵士の攻撃表示は従来の距離・前列判定のままで、この人数との一致は未実装。

一小組の攻撃対象はまだ一つ。複数面・複数相手への同時損害、相手別の面内移動時間、密度圧力は未実装。面は小組の向きと一緒に回る近似なので、旋回後に常に配置をゼロからやり直すわけではない。未配置の面への投入と面間の配置転換には時間がかかる。

向きによる受ける損害の仮倍率は正面から約60度以内が1倍、側面（約60〜120度）が1.25倍、後方（約120度より後ろ）が1.5倍。小組単位の判定で、兵士一人ずつの盾・刀の防御方向や姿勢は計算しない。以下の初期段階の記録にある「観察用」「未反映」は、実装当時の状態を示す。

## 位置づけ

2026-09-05のユーザー希望「戦闘が面で行われることを意識したい」を受けた設計方針。将来のハンニバルの包囲殲滅戦も見据え、接触面・向き・空間・退路を戦闘の土台にする。基本方針は今後の設計であり、実装状況は下記で区別する。現行の挙動は[局所戦闘](local_combat.md)に記載する。

軍勢の人数そのものではなく、実際に接する面へ配置できる兵力が同時に戦う。包囲による不利は、複数方向への対応、混雑、補充と交代の困難、退路閉塞から生じるようにする。包囲フラグだけで一律の大幅な損害補正を与える方式を中心にしない。

## 最初の実装：接触幅の試算（2026-09-05 22:45）

contact_fronts.hに独立した観察用の幾何計算を追加した。小組を向きに従う一辺4.5の正方形として近似し、前・右・後・左の各面を16区間に分ける。区間中心から敵の正方形上の最近点までが距離3以内で、面の外側にあり、途中に他の生存小組の半径2.25の円がなければ候補とする。生存・非敗走の敵のうち最も近い相手一つへ区間幅0.28125を割り当てる。小組中心が4.5未満で重なる相手は対象外とする。

各面に相手別の幅を保持し、合計は一面4.5を超えない。同じ面を複数敵に丸ごと重複加算しない。敗走者は対象から外れるが、遮蔽物としては残る。BattleSimulation::contactFrontsで現在位置から読み取り専用で取得でき、選択タイトルに「接触幅(試算) 前4.5」などと表示する。既存の損害・敵選択・兵士の攻撃表示には書き戻さない。

この幅は有限間隔で測った到達可能な面幅で、厳密な連続区間の重なりではない。量子化誤差、角付近の複数面の扱い、両者で個別に測った幅の対応は追加検証が必要。接触用の正方形と既存の円形占有領域は異なり、寸法4.5・距離3は観察用の仮値。幅をそのまま損害へ適用できる精度が確立したとは扱わない。

Debug / Release各9テストが成功。正面、横ずれ、射程外、敗走者による遮蔽、前後同時接触、同じ面に複数敵、16方向の回転と平行移動、両軍交換、戦闘終了時の非表示を検証した。次は幾何の残る限界を検証し、面ごとの参加上限と全方向の兵力保存を実装する。

## 参加人数と予備の配分案（2026-09-05 23:52）

allocateContactFrontsで、観察用の幅から面別・相手別の参加人数と予備人数を計算する。仮設定は一列・一人あたり幅0.9で、一面の幅4.5に最大5人が参加できる。各区間の容量を合計し、兵力が十分なら容量まで配置、不足すれば全区間の容量比に応じて配分する。配分の合計と予備の合計は小組の残存兵力に一致する。人数は既存の残存兵力と同じ連続量として扱う。

20人で一面だけなら参加5・予備15、前後二面なら参加5ずつ・予備10となる。残存6人で同じ前後二面なら参加3ずつ・予備0。同じ面の複数敵にも、面の人数を相手別の幅に応じて分ける。残存兵力が増えても接触幅が同じなら参加上限は増えない。

選択タイトルに「幅/参加案 前4.5/5.0人 予備案15.0人」の形で表示する。これは現在の条件に対する配分案で、実際に配置済みの人数ではない。配置の時間履歴、内部の通行、旋回による制約、損害・兵士攻撃表示との連動は未実装。無条件に瞬時配分された人数を戦闘へ使わないため、次はこの案へ向けて時間をかけて再配置する処理を加え、その後に損害計算を置き換える。

Debug / Release各9テストが成功。一面の容量、兵力増加時の予備増加、前後二面の配分、少数・小数兵力・ゼロ兵力、非接敵、面順序の交換、同一面の複数敵への配分について上限と兵力保存を確認した。

## 有限時間の面別再配置（2026-09-06 00:06）

小組にFaceDeploymentを保持し、1/60秒ごとに現在の配分案へ近づける。小組全体の移動上限は仮に毎秒2人。目標を超えた面から予備へ戻し、残った移動枠と刻み開始時の予備から不足面へ配置する。戻った兵力は同じ刻みで別の面へ投入しない。戻す人数・入れる人数はそれぞれ超過・不足に比例させ、面の列挙順で優先度を変えない。

接触幅が減っても配置人数は即座には消えず、時間をかけて予備へ戻る。その間の配置人数を攻撃可能人数と同一視しない。実際の損害へつなぐ段階では接触幅と配置済み人数の小さい方を上限にする。面内での相手別の移動時間、個別兵士の経路、混雑による遅延は未実装。面は小組の現在の向きに従い、向き自体の変更は既存の旋回処理を使う。

兵力減少時は前回兵力との比で配置人数を縮小する。増員分は予備となる。接敵がなくなった場合や復帰・交代中は目標を0にして引き上げる。敗走・全滅・戦闘終了では戦闘配置を解除する。Spaceは時間更新ごと止め、Homeは初期化する。Hは既存の接敵戦闘を継続するため、面内再配置も継続する。

選択タイトルは「配置試算 現在→目標」と予備人数を表示する。再配置はSimulationの状態として動くが、損害計算・兵士の攻撃表示にはまだ反映していない。Debug / Release各9テストで、段階的な投入・前後の移動・兵力保存・損失・離脱・敗走・一時停止・固定刻みの一致を検証した。

## 接触面の捉え方

ここでいう「面」は、地面のXZ平面では前線の接触区間として扱う。接触区間には長さ、法線方向、接する両者、そこへ配置される兵力がある。総接触幅は複数区間の合計となる。

同じ接触境界を共有する両軍について、外側にいるだけで片側の攻撃人数が無制限に増えるとは扱わない。一つの区間に同時参加できる人数には、幅・兵士間隔・有効な列数による上限がある。外周の長さだけを攻撃倍率に変換しない。

正面戦から側面・背面にも接敵すると、守る区間が増える。兵力が同じなら、各面へ割り振る人数、予備に残す人数、向きを変える時間の配分が必要になる。内部に兵力が残っていても、接触面へ出る経路と場所がなければ参加できない。

## 再現したい因果関係

| 状況 | 再現したい挙動 |
| --- | --- |
| 狭い正面に大兵力を重ねる | 接触幅の上限を超えた兵力は予備・補充に回り、即時攻撃力に加算されない |
| 正面で戦っているところへ側面の敵が来る | 対応兵力を移すと正面が薄くなり、移さなければ側面の防御が不足する |
| 背後にも接敵する | 同じ兵力を正面と背面で二重に使わず、旋回・配置転換に時間がかかる |
| 内部が密集する | 接触面への移動、旋回、疲労した部隊の交代が滞る |
| 外側に増援を置く | 空いた接触面と通行経路がある場合に参加できる。外側にも混雑は起こる |
| 退路が塞がる | 局所敗走者や消耗した小組が離脱できず、後続の交代も妨げられる |
| 退路が開く | 通行できる幅と経路があれば逃走・離脱を再開する |

補給切断は長期戦の別の時間尺度として扱う。短時間の近接戦闘に、包囲直後の飢餓や弾薬枯渇を混ぜない。士気は重要だが、包囲されたら必ず即座に全軍崩壊するとはしない。

既存のコリジョンは重なりを防ぐ処理であり、兵士の圧力・押し合い・圧死を計算しているわけではない。備全体が止まる現在の挙動を、そのまま内部密度の再現とは扱わない。

## 初期モデルの案

最初は小組の前・右・後・左の4面で試す。面は小組の向きに従うローカル座標を持ち、世界のX/Z軸に固定しない。4面は実装候補であり、検証で斜め方向に不自然さが出る場合は細分化する。

接触面用の幅と奥行きは、兵士の配置と占有領域に対応するよう定義する。現行の中心間射程7.5を、実際の武器長と同一視しない。円形コリジョンとの併用期間は、接触面があっても占有領域や間の味方を飛び越えて攻撃できないようにする。具体的な寸法と兵士間隔は未確定。

各面について、相手との距離・向き・遮蔽を調べ、接触可能な区間を求める。同じ面に複数の敵が接する場合は区間の重なりをまとめ、同じ幅を重複加算しない。角で接する相手を隣の二面へ丸ごと二重登録することも避ける。

概念上の容量は以下とする。これは計算の関係を示すもので、歴史的な定数や調整済みの式ではない。

```text
面の参加容量 = 有効接触幅 / 兵士一人の必要幅 × 有効な戦闘列数
面の参加人数 <= 面の参加容量
面の参加人数 <= その面へ配置済みの人数
全ての面の配置人数 + 予備人数 <= 小組の残存兵力
```

試作の例として、残存20人の小組で一面の参加容量が5人なら、正面だけの戦闘では最大5人が参加し、残りは予備になる。背面にも接触面ができた場合は、予備を背面へ移してから参加する。正面から移すなら、移した分だけ正面の人数を減らす。この「5人」は現在の配分案の仮設定でもあるが、歴史的根拠に基づく値や調整済みの戦闘値ではない。

同じ面に敵が二ついても、面の人数全員で両方を同時攻撃しない。面の人数を接触区間へ割り振る。両軍それぞれの容量・配置人数を計算し、人数が必ず一対一で等しいという制約は置かない。

## 配置転換・損害・表示

面への配分は毎刻み瞬間的に最適化しない。既存の配置を保持し、予備からの補充、他の面からの移動、旋回に有限の時間を使う。微小な角度変化で面が交互に切り替わらないよう、割当の保持と境界付近の安定性を検証する。

まず、幅による参加上限と兵力の保存を確立する。その後、補充速度・疲労・内部の通行可能性を追加する。混雑による低下は通路や再配置時間と結びつけ、原因が説明できない一律倍率を増やさない。

損害は両軍の同じ時点の接触・配分から算出してまとめて適用する。小組の残存兵力を超える損害を別の小組へ流さない。面別の配置に損失を反映し、失った人数が別の面で残存しないようにする。

側背面の仮倍率は移行時に検証し直す。面別の防御不足・旋回遅れ・士気低下ですでに表現した不利を、倍率で重ねて過大にしない。置換する補正と残す補正を明示する。

表示はSimulationの接触面・相手・参加人数に従う。兵士Sprite数を増やしても参加人数や損害は変えない。後列全員が同時に攻撃したり、同じ表示兵士が複数面で攻撃したりしないようにする。

## 実装順序と最初の範囲

1. 接触面の計算を独立させ、面・相手・幅を観察できるデータと検証ケースを作る。最初は既存損害と並行して比較し、戦闘バランスを一度に変えない。
2. 幅による参加人数上限、複数面への配分、予備人数と残存兵力の保存を実装し、旧攻撃係数を置き換える。
3. 補充・面間移動・旋回の時間を追加し、兵士の攻撃表示を面別配分へ対応させる。
4. 混雑と交代、敗走者への追撃、突破・降伏を段階的に設計する。
5. 多数の備・軍勢による包囲シナリオへ広げる。カンナエのような配置の検証は、この基盤の後に行う。

1の観察用試算を実装した。厳密な区間計算への改善と、2の兵力保存・参加上限が次の範囲となる。面別損害・配分・密度圧力・追撃は未実装として区別する。画面の追加表示よりも、接触面の幾何と参加人数モデルを次の戦闘改善の優先事項にする。

## 合格条件

| 検証 | 条件 |
| --- | --- |
| 正面の兵力増加 | 幅が同じなら同時参加人数は容量で頭打ちになり、予備が増える |
| 接触幅の増加 | 十分な配置兵力があれば参加可能人数が増える |
| 正面と背面の同時接敵 | 配置人数の総和が残存兵力を超えず、面を増やすだけで兵力が複製されない |
| 同じ面に複数の敵 | 重なった接触区間と参加人数を二重加算しない |
| 横ずれ・斜め・角 | 接触幅が配置に応じて変わり、面の境界で急激な攻撃力増加が起きない |
| 対称性 | 両軍の交換・全体の回転で、幾何と戦闘結果に不当な差が出ない |
| 射程と遮蔽 | 離れた相手や間の味方を越えて、面の存在だけで損害を与えない |
| 損害と補充 | 損失を全配分へ整合させ、予備が瞬間移動して穴を埋めない |
| 閉塞と再開 | 退路や交代経路が通れない場合は止まり、開けば再開する |
| 再現性 | 固定刻み・描画密度・カメラ回転で計算結果が変わらない |

## 引用された説明の扱い

過去のLLMとの会話は設計の着想として受け取り、史実や用語の出典としては扱わない。カンナエの兵数・損害数・戦闘経過は、この文書では確定しない。

「内線の不利／外線の有利」を一般則として採用しない。内線には移動・補給の距離が短くなる利点もあり、局地的な包囲密集とは区別する。[米陸軍 ADP 5-0（2019）](https://rdl.train.army.mil/catalog-ws/view/100.ATSC/E4166A5D-0FE7-4780-916A-A7E9B227147C-1337689957702/adp5_0.pdf)の内線・外線の説明を参考とする。この資料から古代の近接戦闘の寸法や倍率を導くものではない。
