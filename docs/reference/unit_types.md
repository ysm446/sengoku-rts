# 基本兵種の計画

作成日時: 2026-09-05 12:08
更新日時: 2026-09-06 14:14

関ヶ原で兵種・自律戦闘・隊列を整えてから、他時代へ応用する。ユーザー指定の刀武士を加え、6種類を軸に進める。槍足軽と刀武士は既存の戦闘計算へ接続済み。刀武士・弓足軽・騎馬武者は待機・移動・攻撃の表示素材と兵種確認を実装した。弓はF8の混成戦闘へ射撃・曲射・着弾を接続した。[弓の仕様](ranged_combat.md)を参照。兵種相性と騎馬の突撃は未実装。

| 兵種 | 想定する役割 |
| --- | --- |
| 槍足軽 | 前線を維持する近接歩兵 |
| 刀武士 | 刀の間合いで接近し、斬撃を行う近接歩兵 |
| 弓足軽 | 後方からの射撃支援 |
| 鉄砲足軽 | 装填を挟む射撃。隊列と射撃機会に特徴を持たせる |
| 騎馬武者 | 機動、側面攻撃、追撃 |
| 武将・旗本 | 指揮と士気への影響。本隊を守る意味を持たせる |

槍足軽の近接戦闘を整えてから射撃兵種へ進み、その後に騎馬・指揮系統を具体化する。部隊命令に従いつつ、接敵する兵士だけが攻撃する方針を共通の土台とする。後方は待機・補充を実装済みで、回り込みは経路探索や衝突解決と合わせて検討する。

## 追加した素材

新兵種を動かす[隊列確認](formation_drill.md)を追加した。F6で切り替え、4列×6段の各兵へ兵種別の間隔・加速・旋回を適用する。現段階は移動試作で、固有の攻撃判定や軍勢の階層への統合は未実装。

| 兵種 | 表示上の特徴 | 生成済みの動作 |
| --- | --- | --- |
| 刀武士 | 兜・前立・袖・刀・鞘 | 待機、歩行、刀の振り下ろし |
| 弓足軽 | 弓・弦・矢筒・矢 | 待機、歩行、引き絞りと放弦 |
| 騎馬武者 | 馬体・四肢・たてがみ・尾・鞍・手綱・騎乗者 | 待機、馬の脚運び、騎乗斬撃 |

各兵種は待機8方向、移動と攻撃がそれぞれ8方向×8コマ。既存の槍足軽と同じ64×64の減色Spriteを使う。モデル・動作は表示検証用の初版で、服飾考証や自然な歩容の完成版ではない。騎馬は現時点で刀を持つ1種類。

関ヶ原画面の「兵種を見る」、または `--unit samurai` / `--unit archer` / `--unit cavalry` で確認する。F4で4兵種を循環し、F3で移動／攻撃を切り替え、Spaceで再生する。Homeで動作時計を初期化する。F7で[刀武士の戦闘](melee_profiles.md)を開く。F2で戦闘へ戻ると直前の戦闘兵種（初期値は槍足軽）を使う。

弓の矢は構えと放弦の表示まで。飛翔・命中・射線・味方の遮蔽は今後の戦闘計算へ接続する。騎馬の加速・旋回・円の占有領域は隊列確認で試作済み。戦闘への統合と突撃・追撃は未実装。武将・旗本や鉄砲足軽の素材は未着手。
