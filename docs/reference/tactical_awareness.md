# 小組の索敵と状況判断

作成日時: 2026-09-07 03:10
更新日時: 2026-09-07 03:11

ユーザーの「各隊に索敵と状況判断を搭載する」という希望を受け、実際に移動・攻撃を更新する小組へ最初の判断を追加した。所属する組・隊・備は維持する。隊や備の指揮官が複数小組へ役割を割り振る機能は後続とする。

## 索敵と目標選択

60Hzの固定更新で、歩兵は24、騎馬は32、弓は36未満の範囲にいる生存・非敗走の敵小組を数える。索敵距離と攻撃射程は別で、発見しただけでは損害を与えない。味方の支援と敵の圧力は半径12以内の兵力を合計して比較する。休息中・敗走中・兵力0の小組は戦力合計から除き、自分自身の兵力は含める。表示する近隣味方数は自分を除く。

攻撃線・接近経路の空いている候補を優先し、その中で距離と兵種に応じて対象を選ぶ。射程内の相手は評価を8改善、現在の目標は0.75改善して、わずかな距離差による切り替えを抑える。騎馬は士気40超の正面を向いた槍を6不利に評価し、弓は3有利に評価する。さらに敵の士気・残存率が低い方を選びやすくする。索敵範囲外・兵力0・敗走で対象から外れた敵は保持しない。

これらの数値は描画座標系と試作の比較用の仮値。索敵は全周の距離判定で、視界角・森や地形の遮蔽・霧・最後に見た位置の記憶・伝令の遅延は未実装。攻撃時の遮蔽・射線・衝突検査は従来どおり使う。

## 状況に応じた行動

士気50未満で周囲の敵兵力が味方兵力の1.5倍を超える小組は局所劣勢と判断する。備が止まっており敵が射程外なら単独の接近を控え、新たな両翼展開にも出ない。味方の増援や敵の減少で条件が解消すれば接近を再評価する。既に射程内なら自衛の攻撃は続ける。既存の交代・帰還経路を途中で破棄しない。

歩兵は索敵距離を広げても、独断で接近する対象を距離16未満に制限する。遠くの敵を認識しながら予備として残り、交代や隊列を維持する。騎馬と弓は各兵種の索敵範囲を使用する。備全体への移動・停止命令、前衛交代・休息・敗走と撤退の既存処理を優先する。

判断表示は索敵・接近・交戦・側方展開・予備待機・交代／回復・命令待機・撤退の8種類。目標選択と局所劣勢による接近抑制は今回の追加で、側方展開・交代・撤退は既存の実行中の経路や状態を反映する。各判断のために新しい独立経路を生成しているわけではない。

## 確認方法

アプリを再起動し、Spaceで戦闘を開始する。F8、Spaceで騎馬・弓を含む混成戦を開始できる。小組を左クリックすると、タイトルに判断・索敵した敵数・近隣味方数・局所劣勢の有無・目標小組番号を表示する。Hで停止命令を出すと判断表示も直ちに命令待機へ変わる。Spaceの一時停止では索敵結果も保持し、Homeで初期化する。

## 検証

tactical_awarenessで索敵と射程の分離、範囲外の除外、騎馬の索敵距離、目標の維持と消滅、槍正面と弓の選択、陣営交換、局所劣勢での待機と増援後の接近、遠方索敵で予備が隊列を崩さないこと、停止命令・一時停止・初期化・更新間隔を確認する。既存の戦闘テストでは判断情報の更新間隔一致と両翼の交代・帰還も確認する。

修正後のRelease全28テストとDebug関連3テストが成功。初回は遠方索敵による予備の接近が両翼交代を妨げたため、歩兵の独断接近範囲を制限して解消した。手動操作による表示の読みやすさは未確認。
