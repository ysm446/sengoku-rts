## 目標

ユーザーの希望は、`docs/references/`の参考画像にある合戦図屏風の表現と、Age of Empiresのような雰囲気。初代〜IIを想起する俯瞰・Sprite表現を土台に、追加の希望に合わせ水平回転を可能にする。特定作品の素材や内部実装を再現する指定ではない。

## 現在の試作

黄土色の地面、緑の植生、赤・青の仮兵士、旗、松、陣幕を配置した。全てコードで生成した仮素材で、参考画像の切り抜きは使っていない。GPU描画と画面の構成を評価する段階であり、最終的な画風の達成を意味しない。

兵士はBlenderで生成した64×64・8方向のIdle / Walkを表示する。F2で8方向×2陣営を比較でき、Spaceで歩行を再生・停止、Vで元の仮素材に切り替えられる。[素材生成手順](asset_pipeline.md)を参照。水平回転では見る方向に応じて兵士画像が変わる。表情・旗の揺れ・馬・建物は未実装。コンテンツ領域は1920×1080を基準とする。

## 将来の兵士ごとの動作と倒れた兵士

2026-09-05のユーザー希望として、兵士1体ごとに独立した動きを持ちながら部隊全体の行動に従い、倒された兵士はその場に倒れたまま残る表現を目指す。その後の「進めてください」を受け、個体の追従・動作時計と倒れた場所の保持まで実装した。[実装範囲と制限](individual_soldiers.md)を参照。専用の死亡素材や個体単位の戦闘判定は未実装。

実装案として、部隊は命令・進路・士気などを管理し、兵士は継続的な識別子、現在位置、隊列内の目標位置、向き、動作とその経過時間、生存・倒れる途中・倒れた状態を保持する。歩調や攻撃の開始時刻に個体差を付け、部隊への追従と個々の動作を両立させる。

倒れるときの世界座標と向きを保存し、部隊が前進・撤退しても倒れた兵士が一緒に移動しないようにする。倒れるアニメーションから地面に横たわる表示へ移行し、カメラ回転後も接地と向きが自然に見えることを確認する。

戦闘結果を部隊から個体へ割り当てる範囲と、個体ごとの接触・攻撃判定を行う範囲は実装時に決める。兵力と表示人数の独立性は維持する。倒れた兵士をその場に残すことを基本とし、保持数・表示人数切り替え時の扱い・性能対策は計測後に具体化する。

## 直近の確認項目

1. 通常の俯瞰倍率で、兵士・旗・陣幕の大きさと密度を確認する。
2. 生成できた槍足軽1体を地面や仮素材と比較し、笠・鎧・槍の読み取りやすさと陣営色を調整する。
3. 本素材の32x32・48x48・64x64を比較候補とし、通常倍率と拡大倍率から必要な情報量を判断する。元のDraftの解像度候補に対する追加の検証案で、確定仕様ではない。
4. 実装したRigと歩行を評価し、足滑り、方向切り替え時の見え方、移動時のちらつき、地面への接地、樹木による遮蔽を改善する。

Blenderは素材制作に使用する方針を維持する。今回の仮描画に導入は必須ではなく、本格的なRig・Animation・一括変換の自動化は計画のPriority 5で進める。
