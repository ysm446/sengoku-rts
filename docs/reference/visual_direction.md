# ビジュアルの方向性と最初の比較項目

作成日時: 2026-09-05 10:13
更新日時: 2026-09-05 10:13

## 目標

ユーザーの希望は、`docs/references/`の参考画像にある合戦図屏風の表現と、Age of Empiresのような雰囲気。まずは初代〜IIを想起する固定俯瞰・Sprite表現として試作する。特定作品の素材や内部実装を再現する指定ではない。

## 参考画像から読み取った要素

| 画像の末尾 | 確認できる要素 | 試作への反映 |
| --- | --- | --- |
| `00m06s.jpg` | 黄土色と落ち着いた緑の地形、旗・陣幕・建物が重なる俯瞰の構図 | 色調、カメラ、兵士と背景の大きさの基準 |
| `01m06s.jpg` | 赤い旗、槍、兵士と馬のシルエット、松と陣幕 | 旗と槍が通常倍率でも判別できること |
| `01m24s.jpg` | 衣装の色面、兜の形、人物と樹木の重なり | 拡大時の情報量、背景との前後関係 |

画像だけでは素材の元解像度、アニメーションのFPS、内部の制作・描画方式は断定しない。

## 現在の試作

黄土色の地面、緑の植生、赤・青の仮兵士、旗、松、陣幕を配置した。全てコードで生成した仮素材で、参考画像の切り抜きは使っていない。GPU描画と画面の構成を評価する段階であり、最終的な画風の達成を意味しない。

現在の仮Spriteは32x48・静止画・1方向。兵士数の負荷確認ができるが、表情・動き・旗の揺れ・馬・建物は未実装。遠景のぼけなどの演出も加えていない。

## 次に確認すること

1. 通常の俯瞰倍率で、兵士・旗・陣幕の大きさと密度を確認する。
2. 槍足軽1体をBlenderで画像化し、地面や仮素材と一緒に置いて比較する。本格的な自動化に先行する小さな素材実験とする。
3. 本素材の32x32・48x48・64x64を比較候補とし、通常倍率と拡大倍率から必要な情報量を判断する。元のDraftの解像度候補に対する追加の検証案で、確定仕様ではない。
4. 見た目が成立した素材に方向・歩行を追加し、移動時のちらつき、地面への接地、樹木による遮蔽を確認する。

Blenderは素材制作に使用する方針を維持する。今回の仮描画に導入は必須ではなく、本格的なRig・Animation・一括変換の自動化は計画のPriority 5で進める。
