# 小組の接近・方角・簡易コリジョン

作成日時: 2026-09-05 15:00
更新日時: 2026-09-05 17:02

## 方針

各ユニットが実際に接近して攻撃し、将来ハンニバルの包囲殲滅戦も扱いたいというユーザー希望を受け、物理的な距離・方角・通行可否を優先する。今回の戦闘計算とコリジョンの単位は20人の小組。兵士一人ずつの押し合いは未実装。

## 接近と通行判定

小組ごとに、中心からXZ平面の直線距離16未満にいる生存・非敗走の敵小組を探す。射程内なら攻撃線、射程外なら接近経路が空いている候補を優先し、その中で最も近い相手を選ぶ。すべて塞がれていれば最も近い相手を保持し、射程外では迂回を試みる。備が移動を終えており、敵から離れる命令ではなく、Hで停止していなければ、射程7.5を超える相手へ間隔7.2を目標に接近する。後列は味方が進路を塞いでいれば待つ。敵方向をX/Zの主軸だけに丸めない。

自動接近では小組の占有領域を半径2.25の円として扱う。移動の線分と他の小組中心との距離を調べ、双方の半径と一刻みの移動余裕を確保できない場合は進まない。移動先だけでなく途中のすり抜けも防ぐ。直進が塞がれていれば、敵方向に対する左右6.1・10.4・15.6の中継点を調べる。中継点までと、そこから間隔7.2の接近先までの両線分が通れる最短候補を選び、選択中は「迂回中」と表示する。中継点は到着まで保持し、敵の変更・経路の閉塞・接敵・離脱・敗走で破棄または再探索する。候補がすべて塞がれていれば待機する。複数の曲がり角を使う探索や押し出しは行わない。

備の移動には従来の半幅14の押し戻しを残す。回り込み・交代には従来の保守的な軸平行の通行判定を残す。自動接近・回り込み・交代も、生存している敗走小組を障害物として扱う。備全体の命令移動・撤退・押し戻しにも、小組中心の移動線分と間隔4.5による衝突判定を適用する。

## 備全体の移動

両軍の移動前の小組位置を保持し、移動候補を計算してから確定する。同じ備の非敗走小組は一緒に平行移動するため相互判定から除くが、自軍の敗走者・敵の生存小組は障害物として扱う。相手が同時に動く場合の相対移動と、相手が停止した場合の双方について移動線分を調べる。通常の半幅14の押し戻しも同じ検証を通す。

衝突する候補は備全体の変位を取り消し、移動先を保持して「備の進路閉塞」と表示する。毎刻み再判定し、通路が開くと再開する。勝敗確定後の撤退も対象なので、敗北と撤退先への到着は別の状態になる。初期配置ですでに重なっている場合は離れる動きを許すが、密集した不正配置を一度に解消する機能はない。備全体を分割した通過は未実装で、一つの小組が詰まると備の平行移動全体が止まる。

## 備の簡易迂回

前刻みで移動を阻まれた備は、目的地への直線が通れなければ左右の迂回候補を探す。横幅10～60を10刻み、必要な後退量0・10・20で試す。後退地点・横への中継点・目的地の横の出口・元の目的地を結び、すべての線分を全生存非敗走小組が通れる最短候補を選ぶ。各中継点の備中心は±60以内に限定する。

経路は到着まで保持し、障害物や小組配置の変化で残りの経路が塞がれれば破棄して再判定する。実際の毎刻みの変位にも、両軍同時移動を考慮した既存の衝突判定を適用する。H・新しいMove・全体撤退への切り替えでは旧経路を破棄し、Spaceでは経路ごと一時停止する。迂回中は「備の迂回中」と表示する。目的地が占有されている場合や候補がすべて塞がれる場合は待機する。複雑な迷路、隊列の分割通過、最適経路の保証は対象外。

## 敗走と退路

敗走小組も半径2.25の円として扱う。逃走先への直進、左右30・60・90度の順に候補を調べ、1.0先までの線分が空いていれば通常の1.5倍速で進む。他の生存小組は陣営・敗走状態を問わず障害物とし、相手の一刻みの最大移動量も確保する。左右の優先を保持し、全候補が塞がれれば停止して「敗走中・退路閉塞」と表示する。毎刻み再判定し、出口が開けば再開する。Hは敗走を止めず、Spaceは一時停止する。

局所的な回避なので、いったん逃走先と逆方向へ進む経路や複雑な迷路は解けない。敗走者への追撃・攻撃は未実装で、閉塞だけでは追加損害を与えない。兵士表示は小組へ追従し、個体間の押し合いは行わない。

## 向きと攻撃

小組の向きは毎秒180度を上限に選択相手へ旋回する。中心間距離7.5以内、正面±60度以内、間に他の非敗走小組の占有円がない場合だけ攻撃する。射程7.5は小組の大きさを含む試作値で、歴史的な槍の長さではない。復帰・前列交代・敗走中は攻撃しない。

```text
小組の攻撃係数 = (小組兵力 / 20) × (0.5 + 備の隊列 / 200) × (0.5 + 小組士気 / 200)
相手に与える損害 = 1.2 × 小組の攻撃係数 × 方角補正 × 経過秒
```

相手の現在の向きから見て、正面±60度は1倍、背後±60度は1.5倍、残る側面は1.25倍。複数方向から攻撃された小組は、選んだ一方向にだけ向き直る。両軍の位置・向き・損害候補を確定してから損害を適用する。被害は選ばれた小組へだけ入り、上限を超えた損害を他の小組へ流さない。後列の兵力を備全体の攻撃力として加算する方式を廃止した。

表示兵士の前列も、所属する小組が選んだ敵小組への方向から求める。攻撃可能な小組の生存前列だけが、距離3.5以内の相手へ槍を突く。死亡数の上限は小組の損害、倒れるタイミングは表示上の命中から決める。小組の損害は継続的な試作計算であり、一人ずつの武器接触から集計する方式ではない。

## 待機の理由

敵が見えていても、後列・射程外・旋回中・交代中・停止命令・経路閉塞などでは攻撃しない。攻撃可能な別の相手がいる場合に、塞がれた最短の相手へ固執する問題を修正した。選択タイトルには接敵と攻撃を区別し、対象なし・射程外・旋回中・攻撃線の遮蔽・進路閉塞・停止命令中を表示する。表示は小組単位の理由であり、その小組の全兵士が攻撃する意味ではない。兵士は前列・個別射程の条件も満たす必要がある。

## 検証と後続工程

Debug / Releaseの各8テストが成功。斜め方向の射程外、備の接触領域外での小組同士の攻撃、旋回の遅れ、正面・側面・背後の差、攻撃の遮蔽、8方向の接近と間隔保持、固定刻みの一致を検証した。通常戦闘の描画と保存画像も確認した。

包囲戦へ向けて、多数の備・軍勢、複雑な退路探索、複雑な迂回と混雑解消、敗走者への追撃、兵士一人ずつの接近・接触、実距離に基づく士気伝播を順に検討する。現状の2備・固定区画による士気伝播・簡易回り込みだけで包囲殲滅戦を再現できるとは扱わない。
