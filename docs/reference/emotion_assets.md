# 感情アイコンの素材と仕上げ

作成日時: 2026-09-06 23:52
更新日時: 2026-09-06 23:52

## 使用する素材

`assets/ui/emotions/`の`motivation.png`（炎）、`anxiety.png`（汗をかいた顔）、`fear.png`（青ざめて震える顔）を通常起動で使用する。いずれも32×32 RGBA PNG。アルファは0または255で、吹き出し枠を含まない。絵はX=5〜26、Y=4〜23以内に収め、周囲を透明にする。

共通の吹き出し枠は`src/scene.cpp`で描き、画像を最近傍2倍で合成する。画面上のタイルは64×64px。CMakeが実行ファイル側の`assets/ui/emotions/`へ3枚をコピーする。PNGが欠落、不正サイズ、半透明、全透明・全不透明、または枠と重なる場合はエラーにする。素材指定なしでSceneを作る既存テストではコードの仮素材を使用する。

## 生成元と再作成

原画は内蔵image_genによる`concepts/*-v2.png`で、編集プロンプトは[生成記録](../../assets/ui/emotions/concepts/generation-v2.json)に保存している。透明背景を指定したがRGB画像に市松模様が残ったため、ユーザーの許可を受けてPython/Pillowで仕上げた。APIやCLIによる再生成は使用していない。

再作成にはPythonとPillowが必要。ゲームのビルド・実行には不要。

```powershell
$scriptPath = 'tools/prepare_emotion_icons.py'
python $scriptPath
```

スクリプトは外周からつながる明るい無彩色（RGBの最小値220以上、最大・最小の差24以下）の背景だけを除去する。白目など、輪郭の内側に閉じた白色は保持する。図柄を切り出し、最大22×20へ最近傍縮小し、種類ごとの固定パレットへ置換して32pxの透明キャンバスへ配置する。既存の仕上げPNGを再作成し、確認画像を`build/emotion-icons-preview.png`へ出力する。別の原画や背景へ適用するときはしきい値とパレットを見直し、目視確認する。

## 検証範囲

3枚の透明余白と実寸64pxの図柄を確認。素材テストでRGBAの読み込み、アトラスへの2倍転写、枠の保持、仮素材との差分、欠落時の拒否を検証する。混成戦闘の敗走キャプチャで新しい恐怖アイコンを確認した。手動操作による長時間の混戦評価と高DPI環境の評価は未実施。
