# Prototype 01の接触戦闘・士気・撤退

作成日時: 2026-09-05 11:27
更新日時: 2026-09-05 11:27

## 目的と操作

500対500の2部隊が進軍し、接触戦闘で兵力・隊列・士気を失い、片方が撤退する最小デモ。史実の戦闘力や損害率を再現する数値ではない。Simulationは表示人数を参照しない。

Spaceで開始・一時停止、Homeで初期化。左クリックで選択、右クリックで移動先を変更、Hで停止する。交戦中のHは移動のみを止め、損害を無効にはしない。崩壊前なら移動で離脱できる。撤退中・敗走済みの部隊はMove / Holdを受け付けない。

タイトルバーに進行状態、勝敗、両部隊の状態・残存兵力・士気・隊列を表示する。部隊状態は待機 → 進軍 → 交戦 → 撤退中 → 敗走済み。勝った側はその場で停止する。

## 更新と接触判定

- 1/60秒の固定刻み。渡された時間の端数は保持し、描画fpsと切り離す。一時停止中は時間を蓄積しない。入力時間は有限の0〜3600秒を受け付ける。
- 初期中心は(0, -22)と(0, 22)、目的地は双方(0, 0)、速度は毎秒1.8。
- 部隊の接触領域は向きに依存しない半幅14の正方形。X/Z両軸で接したら交戦し、小さい重なりの軸へ両部隊を押し戻す。境界では中心が±60を超えないよう補正する。
- 隊列は回転せず、兵士の向きだけ敵へ向ける。経路探索・障害物回避・多部隊の衝突解決は未実装。

## 戦闘の仮ルール

双方の初期兵力500、隊列100。初期士気は赤100・青85とし、崩壊の差を観察する。陣営名による戦闘補正はなく、士気を逆にすると勝者も逆転する。同条件なら同時に崩壊する。

各固定刻みの開始状態から双方の損害を計算する。更新順による先制攻撃は発生しない。

```text
攻撃係数 = (兵力 / 500) × (0.5 + 隊列 / 200) × (0.5 + 士気 / 200)
受ける損害 = 6 × 敵の攻撃係数 × 経過秒
隊列の低下 = 1.5 × 経過秒 + 受ける損害 × 0.08
士気の低下 = (1 + (100 - 更新後の隊列) × 0.025) × 経過秒 + 受ける損害 × 0.2
```

兵力・隊列・士気の下限は0。士気20以下、隊列15以下、または兵力100以下で崩壊し、敵と反対方向へ通常の1.5倍速で撤退する。撤退先は中心座標±60の範囲に制限する。到着で敗走済みとなる。

崩壊時に勝敗を確定し、以後の戦闘損害は停止する。同時崩壊は双方敗走。追撃・士気回復・再集結・手動のRetreat命令は未実装。

## 描画と制限

表示兵士数は部隊ごとに「表示上限 × 残存兵力 / 初期兵力」で求め、端数は切り上げる。隊列全体に欠員が散る固定順序を使い、非表示の兵士はサイズ0のInstanceとする。転送数を削減する最適化ではない。

隊列低下に応じた小さな位置の乱れと、交戦中の前後動を追加した。兵士は引き続き地形へ接地する。攻撃専用Sprite・死亡動作・効果音・画面内HUDは未実装で、交戦動作は仮表現。旗と陣幕は初期位置に残す。表示人数を増やしても接触領域や戦闘の結果は変わらない。

## 検証

- Debug / Releaseのビルドと各6件のCTestが成功。
- 戦闘による各値の減少、一時停止、移動離脱、H中の被害、撤退完了、撤退後の命令無効化、初期化、地形端での接触を検証。
- 30fps相当・144fps相当・80秒一括更新で状態が一致。同条件の双方敗走、士気の入れ替えによる勝者の逆転も確認。
- 1,000 / 5,000 / 10,000の表示上限に対する欠員と初期化を確認。
- `dx12_combat`は80フレームで80秒を進め、交戦中と終了時の画像を保存する。Releaseの10,000体・WARPでも成功し、DX12警告・エラーは0件。
- 交戦中の欠員と、敗走後に両軍が離れた描画を目視した。実操作での長時間検証と、戦闘の見やすさ・バランスの調整は今後の作業。
