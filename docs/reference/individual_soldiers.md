# 兵士ごとの動作と倒れた兵士の保持

作成日時: 2026-09-05 11:41
更新日時: 2026-09-05 12:42

## 今回の実装

部隊の行動に沿って兵士ごとに動き、倒された兵士をその場に残したいというユーザー希望を受け、表示用の個体状態を追加した。戦闘の損害・士気・勝敗は引き続き部隊Simulationが決める。個別の近接攻撃対象選択は実装済み。表示側の命中タイミング判定は実装済み。小組単位の簡易回り込みを追加済み。武器形状による衝突判定、兵士間の衝突は未実装。

`src/soldier_visuals.cpp`の`SoldierVisuals`が、位置・向き・動作時計・歩行状態・生存状態・倒れ始めた時刻を保持する。兵士は部隊相対位置に所属小組の変位を加えた場所を目標とし、個体ごとに異なる追従速度と動作時計で移動する。隊列低下によるずれにも個体差がある。歩行は実際の追従状態に応じて再生する。

## 個体の識別と表示密度

表示用IDは各陣営5,000、合計10,000を保持する。1,000 / 5,000 / 10,000体の表示は、その固定集合から間引く。表示数を増減しても同じIDの位置や死亡状態を作り直さない。部隊の実兵力とID数は独立しており、1体の表示が必ず1人の兵力を意味するわけではない。

`Scene`の再生成時に`SoldierVisuals`を引き継ぐため、表示数・素材・F2の確認画面を切り替えても状態が保たれる。表示数を減らすと倒れた兵士も一部が非表示になるが、IDの状態は保持され、増やすと同じ位置に再表示する。現在は非表示IDも含めて更新しており、性能最適化は今後の計測対象。

## 近接攻撃と欠員補充

生存前列は距離3.5以内の最も近い敵前列へ向き、槍突きを再生する。対象が倒れると攻撃を停止する。所属小組が復帰経路を移動中は、自分からの槍突きを止めて移動を優先する。敵からの命中条件は引き続き適用する。停止中の後列は動作時計も進めない。攻撃素材がない場合のみ前後動で代用する。

交戦中は敵方向の主軸（XまたはZ）に沿う71本の列で、生存兵士の順序を維持して目標位置を詰める。補充は[小組](organization.md)の所属内に限定する。後列はそこへ追従して欠員を補充し、死亡位置は動かさない。正面接敵時の小組単位の回り込みは実装済み。斜めの隊列回転、死体回避、任意経路の探索は未実装。

## 倒れる動作

部隊の兵力割合から損害の割当数を求め、交戦中かつ敵兵が近くにいる生存前列へだけ割り当てる。2026-09-05のユーザー希望「直接相手と戦った者だけが倒れる」を受け、後列にも分散していた固定順序を変更した。死亡時の世界座標・向きを固定し、生存 → 倒れる途中 → 倒れた状態へ移行する。倒れる時間は0.8秒。部隊が進軍・撤退しても死亡位置は移動しない。

敵部隊の中心へ向かう方向を前とし、横幅0.75ごとの区間で最も前にいる生存兵士から奥行き0.1以内を前列とする。さらに敵の生存兵士との距離が3.5以内であることを条件に、敵の攻撃相手に選ばれ、動作時計が最大伸長の4コマ目（0始まり、1秒周期の0.5秒）を通過した兵士だけを選ぶ。同じ対象への複数命中は一人分にまとめ、部隊損害の割当上限まで死亡させる。両軍の候補を確定してから死亡させ、片方の更新順による差を避ける。カメラの向きは判定に使わない。

対象が足りない場合は後列へ損害を割り当てず、部隊の損害数と表示上の死亡数に差が残る。後列が前へ詰める動きを実装したが、前列が崩れて敵との距離が開くと追加の死亡表示は止まる。命中タイミングは表示用動作時計による仮判定で、武器と身体の形状の交差は計算しない。長い更新間隔で複数周期をまたいでも、現在の対象への命中候補は一件とし、過去の攻撃対象を再現しない。

既存の静止Spriteを地面へ傾ける仮表現であり、専用の死亡ポーズではない。倒れた後は前向きの静止タイルと世界座標の描画軸を固定し、カメラ回転で向き別タイルを切り替えない。地形の局所的な傾斜に沿った平面を使い、地表から少し浮かせて重なりを避ける。精密な地形への変形は行わない。

Spaceの一時停止中は個体の移動・動作時計・倒れる時間も停止する。HomeではSimulationの世代番号を更新して個体状態を初期化し、倒れた兵士も取り除いて全員を生存状態に戻す。経過時間や部隊の移動だけで倒れた兵士を消す処理はない。

## 更新の範囲と次の改善

個体表示は最新の部隊状態とSimulationの経過時間を用いて更新する。描画頻度によって追従軌跡や死亡位置の細部に差が出る可能性があるが、部隊の戦闘結果には影響しない。過去の全固定刻みを表示側で再生する方式ではない。

槍突き素材は追加済み。次は専用の倒れる・横たわる素材、個体同士の重なりの軽減、前列の接敵表現を検討する。死体の障害物化や個体単位の戦闘判定は別途設計する。

- 生存数と損害の対応、倒れる途中の一時停止、倒れた世界座標と向きの固定、カメラ回転・表示密度変更後の姿勢保持、Homeによる初期化を確認。

- 戦闘終了画像で、青部隊が撤退した場所に倒れた兵士が残ることを目視した。実マウス操作と長時間の性能測定は未実施。
