# 実損害に連動する火花

作成日時: 2026-09-07 02:32
更新日時: 2026-09-07 02:32

戦闘の損害が発生する場所を見分けるため、通常の戦場とF8の混成戦へ火花を追加した。アプリを再起動し、Spaceで戦闘を進めると自動表示される。F8、Spaceで騎馬と弓を含む混成戦を確認できる。

## 表示と通知

白い芯と薄黄色の放射、橙色の粒が散る3コマを合計0.18秒表示する。通常近接は20px、矢は14px、騎馬の突撃は32px。ズーム・描画解像度によらずタイルの画面上の大きさを保つ。透明余白を含むサイズで、実際の図柄はその内側に収まる。外部生成素材は使わず、Atlasの空きタイル36〜38へピクセルを描く。

通知元は60Hzの損害確定処理。残存兵力で上限を切った実損害が正の場合だけ、位置・発生時刻・種類・被害側の陣営と小組・損害量を記録する。攻撃アニメーションだけでは通知しない。射程外や矢の外れでは出ない。攻撃係数と損害の加算順序は維持し、表示側は戦闘計算へ書き戻さない。

近接の位置は攻撃側と被害側の小組中心の中点、矢は実際に損害を与えた着弾位置。複数の近接攻撃が同じ刻みに同じ小組へ当たった場合は、最大の寄与の接触位置を代表として使う。矢と近接が同時なら矢、突撃を含む場合は突撃を優先する。通知の損害量はその刻みの小組への合計値。

被害小組ごとに0.22秒の通知間隔を設け、連続損害で毎刻み発光しないようにする。突撃の初撃はこの間隔より優先する。64件の固定長記録を循環利用し、描画時に期限内のものだけ表示する。記録を描画で消費しないため、再描画やSceneの再作成で通知は増えない。Spaceで停止すると火花の経過時間も止まり、Homeで記録と待ち時間を初期化する。

## デバッグでの読み方と制約

火花は「その小組に実損害が入った」ことを示す。現在は小組単位の連続量の損害計算なので、個々の武器の衝突地点・攻撃アニメーションの命中コマとは一致しない。間引きと代表位置の選択があるため、火花の数から攻撃回数や総損害を数えることはできない。発生位置に固定し、被害小組の移動には追従しない。

## 検証

combat_impactsで実損害との対応、射程外の抑止、接触中点、連続通知の間隔、突撃の区別、矢の命中と外れ、更新間隔の一致、一時停止、期限切れ、初期化、素材の透明部分を確認する。戦闘描画テストでは火花表示を必須とし、最初に表示した画像を通常の保存先に `.sparks.bmp` を付けて保存する。

Release全27テストが成功。矢の着弾位置更新と描画検証の追加後、関連5テストを再実行して成功した。Debugの火花・弓2テストも成功。混成戦の保存画像で小さな白黄色の火花を目視し、DX12警告・エラーは0件。長時間の手動操作や高DPI環境の評価は未実施。
