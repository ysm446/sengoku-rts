# 戦国合戦シミュレーター — ドキュメント案内

作成日時: 2026-09-05 09:53
更新日時: 2026-09-06 08:22

戦国時代の合戦を、3D地形と2DのPixel Soldierで表現する俯瞰型リアルタイム戦闘シミュレーター。Windows向けにC++ / DirectX 12で独自フレームワークを構築し、合戦図屏風が動き出すような画面を目指す。

最初の本格シナリオは関ヶ原。ただし最初のPrototypeでは実際の合戦データを使わず、500人対500人の表示、部隊移動、接敵、戦闘、士気低下、撤退を検証する。現在は地形とSpriteの描画、水平カメラ回転、2部隊の進軍、前列の槍突き、損害・士気低下・撤退が動作する。追加兵種は[基本兵種の計画](reference/unit_types.md)を参照。

まず動かす場合は[開発・起動・検証手順](reference/development.md)を参照する。目標の見た目は[ビジュアルの方向性](reference/visual_direction.md)に整理した。

通常起動で[関ヶ原の史実再生デモ](reference/sekigahara_demo.md)を表示する。模式地形と主要軍勢を時刻操作で観察できる。従来の戦闘試作は画面右上のボタンまたは `--battle` で起動する。
